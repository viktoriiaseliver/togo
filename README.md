# Togo

Дневник собаки: когда выводили, когда кормили, каким был стул. Два тапа —
и вечером никто ничего не выясняет.

Это репозиторий iOS-приложения, собранного по макету из Claude Design.
Тема тёмная и единственная: макет собран на чёрном, светлой пары к нему
нет, и `UIUserInterfaceStyle` заявлен `Dark`. Медицина в приложении —
режим, а не раздел: у здоровой собаки вкладки «Здоровье» просто нет.

---

## Быстрый старт

```sh
git clone <repo> && cd Togo
make bootstrap      # сгенерировать токены и Togo.xcodeproj
open Togo.xcodeproj
```

Проект и токены генерируются скриптами — в репозитории они лежат
сгенерированными, но правятся только через источник:

| Что                         | Источник                        | Команда         |
|-----------------------------|---------------------------------|-----------------|
| Цвета, отступы, радиусы     | `DesignTokens/tokens.json`      | `make tokens`   |
| `Togo.xcodeproj` и схема    | `Tools/generate_project.py`     | `make project`  |

```sh
make device TEAM=XXXXXXXXXX   # поставить на подключённый iPhone
Tools/pull_startup_log.sh     # забрать с телефона крошки запуска
make usage                    # забрать журнал действий за время пользования
make beta      # отдать последнюю сборку тестировщикам в TestFlight
make test      # модульные и UI-тесты
make unit      # только модульные, быстро
make texts     # пересобрать документ для переводчика и каталог строк
make journal   # завести запись в журнале проекта за сегодня
make archive   # архив для App Store Connect
```

Требуется Xcode 27 и iOS 26 SDK (с 21.09, `Makefile`, CI). Цель развёртывания — iOS 17.0, iPhone.

## Локализация: да, через git

Строки живут в `TogoShared/Resources/Localizable.xcstrings` — это обычный JSON
в репозитории. Перевод приезжает пул-реквестом и виден в диффе построчно;
никакой отдельной панели переводов заводить не нужно.

Ключом в строковом каталоге служит сама русская фраза — так устроены
каталоги Xcode. Чтобы на фразу можно было сослаться коротко, у каждой
строки есть ещё и устойчивый id вида `T-B37149`.

Для переводчика, который не работает с git, есть обычный XLIFF:

```sh
make texts                       # собрать docs/TEXTS.md и каталог
make loc-export                  # выгрузить build/loc/en.xcloc и fr.xcloc
make loc-import LOC=build/loc/en.xcloc
```

`docs/TEXTS.md` — один документ со всеми ключами (число — в его шапке,
оно меняется с каждым `make texts`), разложенными
по экранам, с пояснением, где фраза появляется, и с отдельным разделом
про формулировки, смысл которых менять нельзя.

## Дневник переживает переустановку

Два независимых пути, и приложение честно показывает, какой сейчас работает:

* **iCloud** — хранилище настроено на приватную библиотеку пользователя.
  Дневник возвращается сам после переустановки и на новом телефоне.
  Без входа в Apple ID не работает, и экран «Перенос» пишет об этом прямо,
  а не показывает «синхронизировано» на всякий случай.
* **Файл** — «Настройки → Перенос и восстановление» сохраняет всё в обычный
  JSON: собаку, записи, схемы лечения, занятия, семью с выданными правами,
  поездки. При загрузке приложение спрашивает, заменить всё или добавить
  недостающее; повторная загрузка того же файла ничего не задваивает.

## Решения, которые видно в коде

Макет содержит не только экраны, но и правила. Они перенесены как код,
а не как комментарии:

* **Вердикт «просится»** живёт в `VerdictEngine` и имеет пять исходов (пятый — эпизод).
  Меньше четырёх дней данных — всегда «непонятно», и это написано человеку
  прямо. Кнопка «Вывожу» первая во всех исходах: приложение не знает лучше.
* **Занятие** — секундомер и зеркало, а не счётчик корма. `MarkerSession`
  меряет задержку между «он сделал» и маркером; после трёх минут прогресс
  перестаёт писаться.
* **«Как попросил»** спрашивается не каждый раз — при смене сигнала или раз
  в пять выходов (`Diary.shouldAskHowAsked`).
* **Прогулка — режим, а не форма.** Тап по «Гулять» открывает шторку, «Пошли» запускает таймер;
  дальше отмечаешь на ходу, что собака сделала. Записи создаются в конце,
  а время считается от старта — телефон можно убрать в карман.
* **«Если что-то случилось».** Телефон врача в один тап, короткий список
  опасного с разделением «звони сейчас / наблюдай» и карточка с ответами
  на то, что врач спросит первым. Всё собрано из дневника — вспоминать
  в панике не надо.
* **Ничего не теряется молча.** Удаление обратимо пять секунд и оставляет
  след; две записи об одном событии в пределах 20 минут дают карточку
  слияния обоим авторам.
* **Прерывают только три вещи**: доза по часам, окно натощак и лестница
  эскалации. Всё остальное ждёт утреннего брифа.
* **Что бесплатно навсегда** — перечислено в `SubscriptionStore.freeForever`
  и повторено на экране подписки. Без этих вещей приложение молча вредит
  собаке, поэтому они не продаются.

## Журнал действий: две недели пользования вместо догадок

`Настройки → Данные → Журнал действий` — приложение само записывает, что
человек делал и чем это кончилось. Не аналитика: файл лежит на телефоне,
никуда не уходит и содержит только имена действий — «записал · еда ·
сделано». Ни граммов, ни заметок, ни клички, ни имён людей: по журналу
нельзя восстановить ни одной записи дневника.

Экран показывает не список тапов, а ответы:

* **что чинить** — отмена сразу после записи (промах пальцем), удаление
  через минуту, пойманный двойной тап, отказ по правам, сбой сохранения,
  экран, который открыли и тут же бросили, повтор одного действия подряд,
  прогулка без «закончить»;
* **чем пользуются** — какие экраны открывали, что записывали, сколько
  записей в день;
* **что не открыли ни разу** — либо лишний раздел, либо его не нашли;
* **сеансы по шагам** — каждый разворачивается в список действий
  с временем: то самое «что было сделано».

Хранится три недели, дальше подрезается само. Отчёт и сам журнал
отдаются в «Поделиться»; журнал забирается с телефона `make usage`.
Считает всё `UsageReport` — чистая функция над списком действий,
проверенная тестами.

## Чего пока нет

Честный список, чтобы он не потерялся:

* **Маркер с кнопки громкости и с часов.** В макете (8b) маркер работает
  кнопкой громкости, когда телефон в кармане. Сейчас реализован только
  экранный маркер и тактильный отклик; перехват громкости и приложение
  для watchOS — следующий шаг.
* **Отметка «дошло до остальных».** Общий дневник работает: записи
  и отметки доз уходят через CloudKit, слияние разобрано в `SharedDiary`.
  Но поле `isSynced` у записи по-прежнему всегда `true` — состояние
  доставки конкретной строки не отслеживается, и в интерфейсе его нет.
  Показывать зелёную галочку, которая ничего не значит, хуже, чем
  не показывать ничего.
* **Перевод.** Каталог строк собран — `Localizable.xcstrings` — но
  переведён пока только русский. `Settings.isTranslated` проверяет это
  в рантайме, и язык без перевода в настройках не появляется.
  *(Устарело, проверка 24.09.2026: в каталоге `fr` и `uk` по 2042 строки
  из 2056, в `.app` языки fr ru uk; украинский целиком `needs_review` —
  не вычитан носителем. Английского нет.)*
* **Dynamic Type.** `Typography.swift` строит `Font.system(size:)` с
  жёстким кеглем — кегль системы не подхватывается (проверка 24.09.2026,
  открыто в `СТАТУС.md` как спринт).
* **Иконка приложения** сгенерирована скриптом как заглушка
  (`Tools/`-подход к ассетам): перед релизом её должен нарисовать дизайнер.
* **Вторая собака и матрица переноса** закрыты подпиской и показаны;
  переключатель собак — на вкладке «Собака» (`DogSwitcher`), на главном
  его нет намеренно (уточнено 22.09).
* **Свой домен.** Политика и поддержка открываются — страницы собраны
  из `LegalScreens.swift` и лежат на GitHub Pages, ссылки в
  `privacy_url.txt` и `support_url.txt` живые. Но адрес чужой:
  `viktoriiaseliver.github.io/togo/`. Для App Review этого хватает,
  для витрины — нет.
