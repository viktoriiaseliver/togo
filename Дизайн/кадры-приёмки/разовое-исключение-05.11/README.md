# Разовое исключение кормления — кадры приёмки, 05.11.2026

Сняты прогоном `TogoTests` на коммите `64fa22ed`, набор
`КадрПланаДняПромежутокTests.словоТолькоСегодняДоходит`.
Устройство `Togo-b3-shema` (iPhone 16e, iOS 18.6), тёмная тема,
`ImageRenderer`, `scale = 2`, ширина 360 pt.

```
01-план-дня-только-сегодня.png     53 400 б   пометка стоит
02-план-дня-пометка-снята.png      50 891 б   та же сборка, пометка снята
различающихся пикселей             4 278      порог 200
```

## Что на кадре видно, и на него смотрели глазами

Расписание Стича из отзыва 30.10 — 09:30 · 15:30 · 21:30 — с разовым
исключением на сегодня: ужин переставлен на 22:00.

```
Еда · 80 г   09:30 · Эдгар Купер                    ← расписание, жёлтым: просрочено
Еда · 80 г   15:30 · Эдгар Купер                    ← расписание
Еда · 80 г   22:00 · только сегодня · Эдгар Купер   ← исключение, названо словом
```

**Пометка стоит на одном часе, а не на всём дне, и это правка,
которую нашёл ровно этот кадр.** Первая редакция метила все три
кормления — «09:30 · только сегодня» при 09:30 в самом расписании.
Ни один тест этого не видел: все проверяли, что пометка ЕСТЬ.

> Приписка на неизменившейся строке не лишняя, она **неверна**:
> человек читает её как «сегодня всё по-другому».

## Зачем слово, когда час и так на экране

«22:00» в одиночку говорит, что расписание такое. На втором телефоне
это прямая неправда: завтра собака ест в 21:30. Без этих слов второй
человек либо запомнит сдвиг как новое расписание, либо вернёт его
«как было».

## Чего здесь НЕТ: кадра самой шторки

`ImageRenderer` отдаёт `TGSheet` **пустым** — замер 04.11.2026,
записан в `КадрПланаДняПромежутокTests` ниже снятого теста шторки
«Когда дали?». На кадре выходит полоска `TGSheetHandle` и чернота;
два разных состояния дали файлы байт в байт. Причина не установлена,
кандидатов три.

Значит кадр шторки «Во сколько кормить сегодня?» снимается только
UI-прогоном, и **он не снят**. Долг назван здесь, а не в журнале:
читать это будет тот, кто придёт к этому каталогу.

Тёмную тему для такого кадра ставить **снаружи процесса теста** —
`xcrun simctl ui <udid> appearance dark`. `XCUIDevice.shared.appearance`
компилируется, выполняется и не работает: кадры останутся светлыми
при зелёном прогоне.
