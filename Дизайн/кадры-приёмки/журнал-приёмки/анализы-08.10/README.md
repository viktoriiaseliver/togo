# Анализы — приёмка кадром, 08.10.2026, коммит `30c2d94`

Снято по дороге `TogoUITests/Анализы.swift` (её завёл автор экрана
специально под кадр). Восемь состояний × две темы = 16 кадров, все
с парой: светлая 0,80–0,85 против тёмной 0,10–0,18, разница 5–8 раз.
Здесь лежат шесть, несущие выводы; остальные — в прогоне.

Суффикс темы передаётся **только** как `TEST_RUNNER_KADR_SUFFIX`:
`xcodebuild` отдаёт процессу теста лишь переменные с этой приставкой,
снимая её. Без приставки прогон зелёный, восемь кадров снимаются —
и все **без суффикса**, то есть вторая тема молча перезаписывает первую.

## Что принято

| | число |
|---|---|
| пустое состояние: пояснение | 5,55:1 |
| кнопка «Добавить анализ», светлая / тёмная | 18,58:1 / 12,68:1 |
| строка «забор через …» | 16,00:1 |

Алерт «Сохранить без времени?» называет последствие, а не только
спрашивает: «помечен „время не указано“ и на графике встанет пустым
кружком». Две дороги из двух названы словами.

## Что нашлось

**1. Часы от дозы не сходятся с показанным временем.**

```
доза 08:00 · время забора 19:38 → «забор через 11 ч 30 мин после дозы»
доза 08:00 · время забора 19:39 → «забор через 11 ч 30 мин» (тёмный кадр)
арифметика                        11 ч 38 мин и 11 ч 39 мин
```
Два числа на одной карточке расходятся на 8–9 минут. Округление
до получаса — **гипотеза**, не механизм. Цена: протокол контроля
у этого проекта говорит окнами («забор в окне 4–6 ч»), и округление
вниз двигает пробу через край окна.

**2. Шаг 2: нижние поля карточки уходят под закреплённую кнопку.**
При поднятой клавиатуре «Норма от» видно наполовину, «Норма до»
не видно вовсе. Та же семья, что `TGScaffolds:147` — запас под низ
константой.

**3. Орфография подчёркивает единицу измерения.** Под «нмоль/л» стоит
красная волна системной проверки: поле единицы её не отключает.
