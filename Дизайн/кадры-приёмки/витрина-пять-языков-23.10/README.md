# Кадры витрины на четырёх языках — и почему они НЕ залиты

Смена 23.10.2026. Решение Виктории в тот же день: «витрина Togo должна
быть на всех существующих языках».

```
коммит прогона       bc136eb (git worktree /tmp/togo-vitrina)
устройство           iPhone 17 Pro Max · iOS 26.5 · тема dark
размер кадра         1320 × 2868 — совпадает с живыми ru-кадрами в ASC
язык                 xcodebuild test -testLanguage <код> -testRegion <код>
```

## Тексты залиты. Кадры — нет, и это решение, а не недоделка

```
en-US · fr-FR · uk   текст залит и перемерен отдельным запросом
kk                   Apple локаль НЕ ПРИНИМАЕТ — разбор в
                     fastlane/metadata/README.md
кадры всех четырёх   сняты, лежат в fastlane/screenshots/<локаль>/
                     (каталог в .gitignore), по пять на язык
```

**Причина: на каждом из пятнадцати кадров есть русский текст.** Это
не дефект прогона и не дефект языка — это 68 ключей каталога, у которых
**нет словаря `localizations` вовсе**, поэтому они падают на ключ,
а ключ русский.

Замер 23.10 по `TogoShared/Resources/Localizable.xcstrings`:

```
всего ключей                              3476
без словаря localizations вовсе             91
   из них shouldTranslate:false (законно)   18
   из них кириллическая ПРОЗА                68   ← предмет
словарь есть, но записи kk нет                3
контроль в том же замере: ключ «Просится» kk → «Сұранып тұр» — есть
```

**Инструмент считает пробелы среди ЗАВЕДЁННЫХ локализаций**, а у этих
ключей заводить нечего — поэтому «en 3374 · fr 3374 · uk 3374 · kk 3382
из 3403, без пробелов впервые» и 68 русских строк на экране
**одновременно верны**. Это тот же класс, что уже записан про
`AppShortcuts.xcstrings`: отчёт инструмента о себе, прочитанный как факт
о мире. Различитель — не считать дыры внутри каталога, а спросить,
**у скольких ключей словаря нет**.

## Что видно глазом, по кадрам в этой папке

Глазом, потому что ни размер, ни вес, ни код возврата этого не ловят.

```

   (все четыре)     заметное место первого кадра витрины
                    «60 g · съел всё» в ленте

                    дни недели «пн вт ср чт пт сб вс» в календаре —
                    это НЕ ключ каталога, а календарь не на той локали:
                    отдельный предмет, чинится не переводом

                    «НОРМА ВРАЧА ÷ КОРМЛЕНИЯ», «60 г» ×3, «ЧАСЫ»,
                    «слева — как поставили, справа — как выходит»,
                    «план», «Ночь 12 h»
```

`02-needs-verdict` несёт «КАК ПОПРОСИЛ · НЕОБЯЗАТЕЛЬНО» прописными
посреди кадра.

## Почему не залито, хотя разрешение на заливку было

Довод один и он не про качество, а про **обратимость**.

> `залить-кадры.py` заменяет кадр только через слово `заменить`,
> а оно делает **DELETE** в App Store Connect. Удаление в ASC —
> в списке того, чего нельзя без слова Виктории.

То есть заливка сегодня создала бы обязательство, которое исполнить
нельзя: кадры с русским текстом пришлось бы потом удалять, а права
на удаление нет. **Пустая локаль обратима, залитая — нет.**

Второй довод слабее, но он наш записанный класс: версия в
`PREPARE_FOR_SUBMISSION` с кадрами во всех локалях **выглядит готовой
к отправке**, а готовый на вид вывод отключает проверку.

## Что это стоит сделать, когда 68 ключей закроют

Одна команда, каталоги уже лежат на диске:

```sh
source Gamut/.env.asc && python3 ~/Projects/залить-кадры.py Togo применить
```

Сухой прогон 23.10 уже показал, что путь рабочий: `en-US`, `fr-FR`, `uk`
— по пять кадров к заливке, `kk` честно отказывается («локали нет
в витрине»). Таблица локалей в заливщике починена в тот же день
(`78b6908` в хабе): знала две из пяти.

## Кадров пять, а не двенадцать. Чьё это красное

`TogoUITests/ScreenshotTests` — двенадцать тестов, выполняются все
двенадцать, **проходят шесть, кадр пишут пять**.

```
test01Сегодня  ✔ кадр      test03Стул      ✘ нет кнопки «Стул»
test02Просится ✔ кадр      test06Семья     ✘ вкладки «Семья» НЕТ
test05История  ✔ кадр      test07Подписка  ✘ нет кнопки «Настройки»
test08Питание  ✔ кадр      test09Права     ✘ через «Семью»
test12Прогулка ✔ кадр      test10Перенос   ✘ нет «Настроек»
test04Занятие  ✔ БЕЗ КАДРА test11Язык      ✘ нет «Настроек»
```

Шесть отказов — **редизайн, а не язык**: таб-бар теперь
`Сегодня · <кличка> · История · Здоровье`, «Семья» и «Настройки» уехали
под кнопку шапки (`identifier: шапка-меню`, лейбл «Ещё»). Тесты водят
приложение по снесённой раскладке.

> **`test04Занятие` опаснее шести отказов, вместе взятых.**
> У него `guard занятие.waitForExistence(…) else { return }` —
> молчаливый выход. Тест **зелёный**, кадра нет, и в логе про это
> ни строки. «Прошло шесть» и «кадров пять» расходятся ровно на него,
> и заметить это можно только счётом файлов снаружи.

Зонд по `шапка-меню` снят и не дал ответа: кнопка оказалась
`PopUpButton`, по тапу иерархия не меняется. Куда именно уехали
«Семья» и «Настройки» — **не установлено**, и писать «вероятно в меню»
вместо механизма нельзя.

## Чему в этой папке нельзя верить

- **Числа 68 и 3476 сняты 23.10 около 16:00.** Каталог правит другая
  сессия: между двумя моими замерами, разделёнными минутами, он вырос
  с 3403 до 3476 ключей. Перемерять, а не цитировать.
- **«Пять кадров на язык» — это пять ГОДНЫХ ПО РАЗМЕРУ файлов**,
  а не пять годных кадров. Годных для чужой витрины сейчас ноль.
