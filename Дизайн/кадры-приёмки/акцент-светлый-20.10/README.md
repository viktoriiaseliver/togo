# Светлая тема с акцентом #1F4FFF — шесть шагов онбординга

Сняты 20.10.2026 сессией `projects-ee` по прямому поручению Виктории
«не помню, покажи оба».

```
коммит       4cc6eb8 (git worktree /tmp/togo-akcent, НЕ рабочее дерево)
набор        TogoUITests/ПоверхностьОнбординга
стенд        TEMA=light KONTRAST=disabled, симулятор Togo-akcent
снято        6 кадров из 6
```

## Зачем

До этого прогона кадров со светлым акцентом `#1F4FFF` **не существовало
ни одного**: правка `ef22a93` легла 15.10.2026 в 12:39:30, а самые свежие
светлые кадры сняты в тот же день в 11:35 — на час раньше. Решение
«какой светлый акцент верен» принималось бы по плашке цвета, а не по экрану.

то есть инструмент их отличает, а не «не видит цветов вовсе».

## Пара для сравнения

Прежний акцент `#0E14A1` — `../онбординг-шесть-шагов-14.10/01-приветствие-light.png`
(коммит `ff39462`, 14.10, тот же набор, тот же стенд).

> **Граница: кадры с разных коммитов, между ними шесть дней и 226 правок
> в коде.** На кадре 20.10 есть строка «Меня позвали в семью», которой
> 14.10 не было. Для цвета это безразлично — он померен по пикселю, —
> но «всё остальное одинаково» утверждать нельзя.
