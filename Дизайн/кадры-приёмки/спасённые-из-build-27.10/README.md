# Кадры, спасённые из `build/` 27.10.2026

Двадцать шесть кадров существовали только под `.gitignore`, то есть
нигде. Второй такой случай: 12.10 оттуда спасли 116.

**Приёмкой они не являются.** Кто снял, на каком коммите, в каком
прогоне — не установлено, а `build/` перезаписывается каждым прогоном.
Годны как улика, что экран однажды нарисовался; не годны как
доказательство, что верно.

Дороже остальных двадцати четырёх два:
`онбординга__130-…-НЕГОДЕН-клавиатура-поднята` — один из трёх негодных
кадров с клавиатурой, негодность объявлена **в имени**;
`онбординга__154-режим-дня-КОНТРОЛЬ` — контрольный слот, по которому
15.10 сверяли ось. Контроль под `.gitignore` контролем быть перестаёт.

Как найдены и чем это стоило — `git log` этого каталога. Разбор
ложного нуля, который сперва сказал «кадров нет», — в своде хаба,
перечень ложных нулей.
