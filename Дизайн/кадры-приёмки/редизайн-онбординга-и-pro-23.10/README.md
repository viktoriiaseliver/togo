## Чего на кадрах нет и не будет

- **Фотографии во весь экран на приветствии.** Фото в макете —
  плейсхолдеры Unsplash, README пакета говорит «в продукт не включать»;
  своего фото у человека на первом запуске нет по построению. Стоит
  иллюстрация «линия», сцена `onboarding`.
- **Ленты семей с цитатами и строки «ещё 1 200 собак».** Это отзывы
  несуществующих людей и число, которого никто не мерил.
- **Кнопки «С примером».** Демо-дневник некуда положить: `SeedData`
  строит контейнер в памяти и живёт только под `-UITesting`.

Каждое — вопрос к Виктории, а не недоделка; разбор в головах
`OnboardingFlow` и `PaywallScreen`.
