## Чего здесь нет и почему

**Кадра с поднятой клавиатурой нет.** Прогон 17:35 упал на том, что
после «Добавить человека» не открылся лист «Новый участник»: ворот
`ProGate.familyBeyondTwo` при пяти участниках закрыт, а переключатель
Pro в настройках сообщил «нажат», не включив. Функция возвращала
намерение вместо исхода — починено в `4033063`, туда же добавлен кадр
**до** утверждения: в этом прогоне улику съел собственный фильтр.

**Кадров роли гостя нет.** `ГостьНеПишет` успел отыграть только
контрольный тест — владелец записывает еду и видит «Отменить»,
`passed` за 9,9 с. Это значит, что путь рабочий и тест про гостя будет
осмысленным; сам гость прерван освобождением машины.

**Кадров исходов приёма приглашения нет** — набор не запускался.

## Что из этого следует знать читающему

`print(…)` из теста **в сохранённый лог не попадает**: `прогон-ui.sh`
хранит лог приложения, а печать теста идёт в лог раннера. Замер —
`grep "ВЫВОД ДЛЯ ГЛАЗА"` по двум логам даёт **0**.

> Печать, которую нельзя прочитать, равна отсутствующей.

Поэтому выводы по этим кадрам сделаны глазом, а не по строкам,
которые тесты для этого печатают.
