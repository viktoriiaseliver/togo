## ДОРОГИ ЭТОЙ В GIT НЕТ — вот она дословно

Тест жил только в `git worktree`. В `ScreenshotTests` он не положен
нарочно: этот набор — **генератор витрины**, и десять лишних PNG
уехали бы в `fastlane/screenshots` к соседу, который его ведёт.
А без текста здесь запись «снято дорогой ScreenshotTests» была бы
утверждением о коде без способа проверить его за минуту. Поэтому
текст лежит тут, в кадры вставляется копипастом:

```swift
func test13ТостНаложение() {
    app.buttons[т("Гулять")].firstMatch.tap()
    let пошли = app.buttons[т("Пошли")].firstMatch
    XCTAssertTrue(пошли.waitForExistence(timeout: 10))
    пошли.tap()

    let занятие = app.buttons[т("Занятие")].firstMatch
    XCTAssertTrue(занятие.waitForExistence(timeout: 5), "таймер должен пойти сразу")
    занятие.tap()
    XCTAssertTrue(app.staticTexts["Отмечено · Занятие"].waitForExistence(timeout: 3),
                  "первого тоста нет — накладываться нечему")

    app.buttons[т("Стул")].firstMatch.tap()
    for кадр in 1...6 { capture("13-тост-\(кадр)") }
}
```

Строка с `waitForExistence("Отмечено · Занятие")` — не украшение:
без первого тоста накладываться нечему, и прогон тогда мерил бы
не то, о чём молчал бы зелёным.

## Что показали кадры, чего не показал бы тест

Плашка **одна**, галочка **одна**, пилюля не сдвинулась — значит
накладываются не два тоста, а **текст сам с собой**. `if let toast`
остаётся истинным, вид не пересоздаётся, `transition` не срабатывает;
меняется только строка внутри — и меняется она внутри
`withAnimation(.spring(duration: 0.28))` из `AppState.show`.
Смену строки в анимации ведёт `contentTransition`, по умолчанию
`.interpolate`, то есть перекрёстное растворение: обе строки
нарисованы разом.

Правка — `.contentTransition(.identity)` на плашке
(`Togo/App/RootView.swift`). `transition` прибытия оставлен: плашке
приезжать анимацией **задумано**, подменять в ней слова — нет.

### Чем померить НЕ вышло

`-UIAnimationDragCoefficient 10` в аргументах запуска окно **не
расширил**: SwiftUI своим аниматором этот флаг не читает. Проверено
положительным контролём — прогон с замедлением и **без** починки дал
ровно ту же картину (каша на 1-м кадре, чисто со 2-го). Записано,
чтобы следующий не тратил на это прогон.
