# Handoff: Togo · iOS 28 (тема «Кино», 5 языков)

## Обзор
Редизайн iOS-приложения Togo (дневник собаки для семьи) в эстетике iOS 28: Liquid Glass поверх фотографии, крупное показание «сколько дома», одна главная кнопка по состоянию дня. Пакет содержит последние прототипы на пяти языках (RU, EN, FR, KK, UK), новые токены поверх Graphite, все переводы в форматах для Xcode и рекомендации по внедрению.

## О файлах
Файлы в `prototypes/` — **дизайн-референсы в HTML**, а не код для продакшена. Задача — воссоздать их в существующем SwiftUI-проекте Togo (`Togo/Togo/Features/*`, `TogoShared/DesignSystem`) его средствами: Asset Catalog, SF Symbols, системные материалы, `String(localized:)`. HTML не переносить.

Открыть прототип: положить папку `prototypes/` целиком и открыть любой `Togo-XX.dc.html` в браузере (нужен `support.js` рядом). Слева — панель состояний дня и тем, справа — «Все экраны» (прыжок на любой экран).

## Точность
**Hi-fi** для «Сегодня», «На улице», шторок, вкладок и подэкранов: цвета, размеры, тексты финальные. Фото-заглушки (Unsplash) — **плейсхолдеры**: в продукте фото пользователя (см. «Фон»).

## Навигация (решено)
- **4 вкладки:** Сегодня · {кличка} · История · Здоровье. Семья — первая строка во вкладке собаки. «Здоровье» скрыто у помощника без `seeMedical`.
- **Шапка:** одна кнопка «…» (меню): Настройки · Другой день (на «Сегодня») · Семья (на вкладке собаки). Больше кнопок в шапке нет.
- **Низ «Сегодня»:** главная кнопка по состоянию + вторая (одинаковые: высота 60, `flex 1/1`, 17 semibold) + круглая «+» 60 → шторка «Записать»: Инцидент (первым, красный) · Стул · Еда · Ещё.
- Глубина ≤ 3: вкладка → экран → форма (`docs/NAVIGATION.md`).

## Экраны
Полный список — `SCREENS.md`. Ключевые:

### Сегодня
Сверху вниз: статус-бар → шапка (кличка + подпись «вес · дежурит», «…») → пилюля второго состояния (≤ 1) → баннер (≤ 1) → **панель показания** (высота 360, радиус 32, без своего фото в «Кино» — фон даёт фото экрана): чип состояния слева сверху, стеклянная панель снизу (радиус 24, `--g-strong`, блюр 28 / 180 %) с показанием SF Rounded 300 56 pt + «с · до» 14 semibold + полоса-косточка → строка «Дальше · {когда}» 17 semibold → MergeCard (если есть) → «Впереди» (≤ 2 несделанных) → «Лента дня».
- Цвет панели = состояние: обычное — стекло; натощак — янтарь `rgba(255,194,51,.92)` с текстом #2A1D00; доза — `rgba(31,79,255,.92)`, текст белый, главная кнопка синяя; тревога — `rgba(213,37,25,.92)`; ночь — фото с фильтром `saturate(.3) brightness(.7)`.
- Порядок состояний: тревога > доза > натощак > эпизод > режим с концом > запас ≤ 3 > нет сети > обычно. Второе — в «Дальше», третье — пилюлей.
- При прокрутке > 120 pt появляется компактная строка «время · дальше».

### Лента дня
Сплошные строки `surface-card` (не стекло — сквозь стекло просвечивали кнопки свайпа). Строка: время 44 pt справа-выровнено 15 semibold · кружок 40 (цвет категории, значок #111; доза — скруглённый квадрат 12) · заголовок 17 + подпись 14. Между выходами — строка «дома 3 ч» с `home`. Свайп влево → «Изменить» / «Удалить» (72 pt), удаление — тост с «Отменить» 5 с.

### На улице
Фон — фото, кольцо + таймер SF Rounded 76, «Пописал» / «Стул» (сплошные `surface-raised`, не стекло), слайдер «Домой». Тост — сверху (740 pt от низа в кадре 874), не перекрывает кнопки. Таймер не уходит в минус: `elapsed = max(0, now − start − paused)`.

### Остальные
Вкладки и ~40 подэкранов собраны из блоков: Hero (фото + стекло), Metric (число 48 + столбики 14 дней), Banner, Rows (ListRow), Grid (матрица), Checks (сборы), Photos (сетка 3×), Widgets (мокап виджетов и Live Activity), Button. См. `blocksFor()` в прототипе.

## Фон приложения (новое, во всех языках)
Настройки → «Фон приложения». Режимы:
- **Как задумано** (`auto`, по умолчанию) — у каждого раздела своё фото.
- **Одно фото для всех** (`single`) — первое из пользовательских или фото собаки.
- **5 фото вперемешку** (`random`) — фото экрана = хэш(ключ экрана + seed запуска) % N; меняется при каждом запуске.
- «Добавить фото» (до 5, уменьшать до 1000 px, JPEG 0.8), «Убрать мои фото».
Хранить в `UserDefaults`/App Group (виджеты используют то же фото). В коде — один `BackgroundStore`, экраны спрашивают `background(for: ScreenKey)`.

## Тема «Кино»
Тема по умолчанию (`data-look="cinema"` + `data-theme="dark"`). Отличия от тёмной Graphite: фон #000, карточки #1C1C1E, главная кнопка **белая** с текстом #111, крупный заголовок 36 / −0.025. Фото под шапкой на каждом экране, высота 640 (Сегодня) / 420 (вкладка) / 360 (подэкран), маска и затемнение — `--bd-scrim`, `--bd-mask`. Светлая и тёмная темы остаются (переключатель в Настройках).
**Отступление от Graphite:** белая primary вместо индиго и чёрный фон вместо графита — зафиксировать в `РЕШЕНИЯ-ДИЗАЙНА.md`, если тему утверждают.

## Состояние
Модель данных прототипа (`seed()` в коде) повторяет `TogoShared/Models`: `entries[]` (type, ts, v, unit, detail, who, marks, photos, deleted, origin), `walk {start, marks, paused, pausedTotal, origin}`, `doses[]` (минуты от полуночи), `stock`, `alarm`, `episode`, `trip`, `doseLock`, `duty`, `pro`, `behavior`, `nfc`, `theme`, `bg {mode, items[]}`. Ключи хранения раздельные по языкам (`togo-ios28-v5`, `-en1`, `-fr1`, `-kk1`, `-uk1`); фон — общий `togo-ios28-bg`.

## Локализация
- Исходный язык — **русский**; ключи `Localizable.xcstrings` = русская строка. Все переводы помечены `needs_review`.
- 1 287 строк, из них **154 — фрагменты** склейки (`" мин"`, `"гулял в "`, `" из "`). В xcstrings они **не включены**: их нужно заменить на строки с интерполяцией и плюралами, например `"Гулял %@ назад"`, `"%lld из %lld"`, `"Запас на %lld дн."` (plural variations для ru/uk/kk). Список фрагментов — колонка `fragment` в `strings.csv`.
- Плюралы: ru/uk — one/few/many/other, kk — one/other, en/fr — one/other. В прототипе формы дней («день/дня/дней») захардкожены — заменить на `stringsdict`-варианты.
- Даты — `Date.FormatStyle` по локали (`ru-RU`, `en-US`, `fr-FR`, `kk-KZ`, `uk-UA`). Кличка не переводится; имена людей — данные, не строки.
- Казахский и украинский — машинного качества по стилю; перед релизом — вычитка носителем (особенно склеенные фразы).
- Длина: FR/KK самые длинные (+25–35 %). Прототип проверен на 402 pt; проверить 320 pt + AX1 на FR и KK.

## Рекомендации
1. **Сначала токены и тема.** Перенести `togo-ios28.tokens.json` в Asset Catalog (`Cinema` как отдельный набор цветов или как `ColorScheme.dark` + флаг `look`). Стекло — системные материалы iOS 26+ (`glassEffect`), а не свои rgba.
2. **Один `ReadingTone`** (normal/fasting/dose/alarm/night/walk) управляет панелью, чипом, главной кнопкой и тоном фото — как `TONE` в прототипе. Не размазывать цвета по экранам.
3. **Лента — `List` со `swipeActions`**, не кастомный свайп. Кружок категории — один `CategoryBadge(type:)`.
4. **Цели касания ≥ 44 pt, шрифт ≥ 12 pt** — прототип уже подогнан; держать тест `ПолКегляTests` и добавить такой же на цели касания.
5. **Строки — только через `String(localized:)` с интерполяцией.** Склейки из прототипа не переносить.
6. **Фото пользователя** — `PhotosPicker`, хранение в App Group, уменьшение до 1000 px; виджет берёт то же фото.
7. **Reduce Transparency** → `surface-raised` без блюра; **Reduce Motion** → без анимации ауры/кольца (флаги `data-rt`, `data-rm` в прототипе).
8. **Не переносить:** левую и правую панели прототипа, переключатель тем в панели, Unsplash-фото, `Material Symbols` (заменить на SF Symbols по таблице в `guidelines/` Graphite).
9. Перед релизом — проверить контраст новых `--cat-*` в светлой теме и повышенном контрасте (в Graphite их нет).
