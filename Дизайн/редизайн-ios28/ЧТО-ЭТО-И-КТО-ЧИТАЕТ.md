## `prototypes/tokens/` — второе поколение, лежащее рядом с первым

Это ровно тот случай, от которого написано правило
`.claude/rules/токены-и-дизайн.md` («Два поколения токенов лежат рядом,
и инструмент читает старое»). `README.md` пакета говорит про эти файлы
«**= Graphite, без изменений**». **Против нашего git это неверно для
трёх файлов из одиннадцати:**

```
файл            пакет   git (DesignTokens/ядро-дизайна/tokens)  cmp
accents.css      2009   2009                                    совпал
base.css         1023   1023                                    совпал
icons.css         276    276                                    совпал
motion.css        724    724                                    совпал
spacing.css      2177   2177                                    совпал
styles.css       2616   2616                                    совпал
typography.css   6092   6092                                    совпал
colors.css       4591   6148                        ← РАЗОШЁЛСЯ
system.css        289    296                        ← РАЗОШЁЛСЯ
togo.css         1518   3173                        ← РАЗОШЁЛСЯ
palette.css      6248      —                        ← В GIT ТАКОГО НЕТ
                                figma-variables.json  только в git
                                tokens.dtcg.json      только в git
```

Расхождение **не в значениях, а в ИМЕНАХ**: пакет зовёт акцент
`--action-primary`, мы — `--accent`; `--poster-*` у пакета переехали
из продуктового слоя (`togo.css`) **в ядро** (`colors.css`), а у нас
они в продуктовом. Это разные схемы именования, а не свежая копия нашей.

> **Запись о переименовании — утверждение со стороны источника,
> а не о нашей системе.** «= Graphite, без изменений» говорит «у меня
> это звалось так», а не «у вас это то же самое».

**Три живых инструмента читают наш каталог, а не этот:**
`TogoTests/SpacingGridTests.swift`, `Tools/contrast_graphite.py`,
`Tools/сверка_токенов_с_фигмой.py`. Ни один не должен быть переведён
сюда: здесь копия прототипа.

*Проверить за минуту:*
```bash
for f in Дизайн/редизайн-ios28/prototypes/tokens/*.css; do \
  b=$(basename "$f"); g="DesignTokens/ядро-дизайна/tokens/$b"; \
  [ -f "$g" ] && { cmp -s "$f" "$g" && echo "совпал $b" || echo "РАЗОШЁЛСЯ $b"; } \
  || echo "только в пакете $b"; done
```

## Чего в пакете НЕТ — и это надо знать до работы

- ~~**Повышенного контраста у темы «Кино» нет вовсе.** Ноль блоков
  `[data-contrast="high"]`, слово `contrast` не встречается ни разу.~~
  **ЛОЖНО для той редакции пакета, что лежит в репозитории. Снято
  26.10.2026, перемер ниже.** Повышенный контраст у «Кино» ЕСТЬ,
  и зовётся он **`cinemaHC`** — отдельным режимом, а не блоком
  со словом `contrast`:

  ```bash
  # по ИМЕНИ РЕЖИМА, а не по слову «contrast»:
  grep -n cinemaHC tokens/togo-ios28.tokens.json       # строка 221
  # под этим ключом 23 ЗНАЧЕНИЯ (surface, text, line, action, glass)
  grep -o 'data-contrast' tokens/togo-ios28.css | wc -l # 1, не 0
  grep -n 'data-contrast' tokens/togo-ios28.css
  #   36:[data-look="cinema"][data-theme][data-contrast="high"] {
  grep -o -i contrast tokens/togo-ios28.tokens.json | wc -l  # 1, не 0
  #   254: "note": "Отдельная шкала, не равна cinema. Включается
  #        UIAccessibility.isDarkerSystemColorsEnabled /
  #        colorSchemeContrast == .increased."
  # КОНТРОЛЬ того же прохода: 1F4FFF → 3 в json, 1 в css. Греп жив.
  ```

  > **Старое утверждение держалось на `grep` по СЛОВУ, которым режим
  > не называется.** Режим есть, значений 23, блок в CSS на 36-й
  > строке — и всё это невидимо для запроса «contrast». Ложный ноль
  > по неверному имени, и прочитан он был как факт о пакете.

  И вторая половина, объясняющая происхождение: прежний замер, скорее
  всего, был снят по **другой редакции пакета**. Копий хендоффа
  в `~/Downloads` шесть, редакций три, и различать их можно только
  хешем:

  ```
  2efce20f  безномерная и «2», 22.10       109 значений, cinemaHC — 0
  25b79a90  «3», 23.10 10:35               вторая редакция
  ca8d9c26  «4»/«5»/«6», 23.10 11:45       171 значение, cinemaHC — 23
  ```

  В репозитории (`tokens/togo-ios28.tokens.json`, коммит `3249684`)
  лежит **`ca8d9c26`** — свежая. В старой `cinemaHC` действительно
  нет, и там утверждение было верным. **Имя копии не называет
  редакцию**, поэтому ссылаться на пакет только хешем.

  Что из прежней записи ОСТАЁТСЯ в силе: наша красная линия
  «продуктовые цвета литералом в HC не попадают» — тема «Кино»
  записана литералами, и проверять их попадание в HC всё равно надо
  по `Tools/contrast_graphite.py`, а не по наличию режима в пакете.
  Рекомендация 9 пакета («проверить контраст новых `--cat-*`
  в светлой и повышенном контрасте») тоже остаётся: значений

## Два числа пакета не сошлись с перемером

**«74 экрана есть в прототипе» — плитка, а не замер.**
`reference/coverage.dc.html` печатает плитки `74 / 5 / 3`, а в его
собственном массиве `G`, из которого рисуется таблица:

```
OK    55      ← плитка говорит 74
PART   5      ← сошлось
SYS    3      ← сошлось
всего 63 записи в 9 группах
```

Механизм расхождения **не установлен** — возможно, плитка считает
экраны, а строка таблицы покрывает несколько («Сегодня, 14 состояний»
— одна запись). Правдоподобно, но не померено, и подставлять это
объяснением нельзя. В наряд идёт **55**, с оговоркой.

*Проверить за минуту:*
```bash
grep -o 'OK\]' Дизайн/редизайн-ios28/reference/coverage.dc.html | wc -l
```
