# Togo iOS 28 · переводы

Все тексты всех экранов прототипа: 1 287 строк × 5 языков (ru — исходный, en, fr, kk, uk).

| Файл | Для чего |
|---|---|
| `Localizable.xcstrings` | Xcode String Catalog. Ключ — русская строка, переводы в состоянии `needs_review`. 1 133 цельные строки. |
| `strings.csv` | Таблица для переводчиков и вычитки: `ru,en,fr,kk,uk,fragment` (UTF-8 с BOM, открывается в Numbers/Excel). |
| `strings.json` | Тот же список массивом объектов `{ru,en,fr,kk,uk,fragment}`. |
| `ru.json` … `uk.json` | Плоские словари «русская строка → перевод» по языку. |

## Фрагменты
154 строки с `fragment: true` — куски склеенных фраз из прототипа (`" мин"`, `"гулял в "`, `" из "`). В xcstrings не включены. В коде заменить на строки с интерполяцией и плюралами: `"Гулял %@ назад"`, `"%lld из %lld"`, `"Запас на %lld дн."`.

## Плюралы
ru, uk — one / few / many / other; kk, en, fr — one / other. В прототипе «день / дня / дней» захардкожены — перенести в варианты String Catalog.

## Вычитка
kk и uk — перед релизом прочитать носителю. fr и kk длиннее русского на 25–35 % — проверить 320 pt + AX1.
