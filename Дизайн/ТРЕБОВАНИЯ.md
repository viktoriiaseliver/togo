# Требования к файлу Figma

Читает тот, кто **рисует**. Цель одна: чтобы из макета получался
простой Swift, а не разбор того, что имелось в виду.

Тариф — **Professional**. Всё ниже с ним совместимо; где потолок рядом,
это сказано числом.

---

## 1. Переменные заводятся первыми — до единого компонента

> **Компонент, собранный на числах, невозможно перекрасить темой.**
> Переделать его потом дороже, чем завести переменные сейчас.

Готовый путь есть: `DesignTokens/ядро-дизайна/figma-plugin/` заводит
199 переменных со `scopes` и code syntax, 15 текстовых стилей и наборы
вариантов (версия 15-08, акцент Indigo · Orange · Pink). **Plugins → Development → Import plugin from manifest…**
Тариф для него не нужен. Рисовать руками то, что заводит плагин, —
лишняя работа и источник расхождений.

### Три коллекции, ровно как `tokens.json`

```
Primitive  →  Semantic  →  Component
```

- **Primitive: `scopes = []`** — спрятать из всех пикеров. Тот, кто
  рисует экран, видит только `Semantic` и `Component`. Исключение
  одно: полупрозрачные оверлеи получают `["EFFECT_COLOR"]`, иначе
  их не выбрать в пикере тени.
- **Semantic не держит сырой hex — только `VARIABLE_ALIAS`
  на Primitive.** Нужно новое значение → сперва примитив, потом алиас.
- **`scopes` явно у каждой переменной. `ALL_SCOPES` запрещён** — это
  умолчание, и оно засоряет каждый пикер в файле:

  | Роль | `scopes` |
  |---|---|
  | фон | `FRAME_FILL`, `SHAPE_FILL` |
  | текст | `TEXT_FILL` |
  | обводка | `STROKE_COLOR` |
  | отступ | `GAP` |
  | радиус | `CORNER_RADIUS` |
  | размер | `WIDTH_HEIGHT` |
  | кегль | `FONT_SIZE` |
  | семейство | `FONT_FAMILY` |

  У `BOOLEAN` scopes не поддерживаются вовсе.
- **Code syntax iOS у каждой переменной** — точечная нотация имени
  из Swift: `Token.Surface.card`, `Token.Ink.primary`, `Token.Space.s28`.
  Префикс `--togo-` живёт **в code syntax, не в имени**.
- **Имена путём со слешем, lowercase:** `color/bg/primary`, `space/28`.
  Никогда camelCase внутри имени и никогда пробел внутри сегмента.

### Режимы — и потолок, который рядом

| Коллекция | Режимы | Потолок Professional |
|---|---|---|
| тема | `Dark · Light · Dark HC · Light HC` | **4 — в упор** |
| акцент | `Indigo · Orange · Pink` | 3 — запас на один |

> **Пятый режим темы на Professional невозможен. Четвёртый акцент —
> возможен, пятый нет.** Замерено по `figma-variables.json` 13.10.2026;
> прежняя редакция этого абзаца называла акцент «Lime · Orange · Sky ·
> Pink» — это поколение, которого нет ни в коде, ни в токенах.

**Повышенный контраст обязан быть режимом, а не пометкой.** Замер
07.10.2026: продуктовые цвета, записанные литералом, в HC не попадают
**по устройству** — блоки `[data-contrast="high"]` живут в ядре
(`colors.css`), а у продуктового слоя (`togo.css`) такого блока нет
вовсе. Без HC-режима в макете тот, кто рисует, **никогда не увидит
экран человека, попросившего усилить контраст**.

И правило HC, которое легко применить в минус: **«в повышенном
контрасте темнее» — про тёмный текст.** Подпись на цветном блоке
белая, и «контрастнее» для неё значит «непрозрачнее»; потемнение
уронило бы контраст. Замер: `#FFFFFFE0 → #FFFFFF` дал 5,04 → 5,99.

## 2. Компоненты

- **Имя компонента = имя типа в Swift.** Группа = страница библиотеки.
  Тогда сверка занимает минуту, а не разбор.
- **Свойства компонента = параметры типа.** Варианты в формате
  `Property=Value`, значения Title Case (`Size=Medium`), булевы —
  нативные `true`/`false`, не `Yes`/`On`.
- **Состояние — вариант, а не свойство инстанса:** `disabled`,
  `pressed`, `hidden` → `State=Disabled`.
- **Внутренние подкомпоненты с префиксом `_`** (`_Button/IconSlot`),
  документационные — с точкой (`.ExampleCard`). И то и другое
  прячется из панели Assets.
- **Один слот — одно свойство.** `INSTANCE_SWAP` для иконки,
  `SLOT` для свободного содержимого. Безымянный вложенный инстанс
  ловится только поиском по имени слоя — и ломается, как только слой
  переименуют.

### Раскладка

- **Auto-layout всюду, где у детей есть структурная связь.**
  Абсолютные координаты — только для декора, который действительно
  висит точкой.
- Пиксельная дисциплина допустима **только** на внешнем фрейме экрана
  и системной хромировке. Нав-бар и таб-бар авторены под ширину своего
  безеля: экран 393 + нав-бар 402 = рассыпалось.
- **Одна раскладка на элемент.** Переносится в узком месте — это
  **один** компонент с auto-layout, а не два фрейма. У Togo в коде
  запрещён `ViewThatFits`: он держал в дереве обе раскладки,
  и озвучка находила две кнопки «Отменить» — видимую и невидимую.

### Шрифт и иконки

- **Иконки — SF Symbols по имени роли**, через плагин. Своих
  нарисованных иконок быть не должно.
- **Шрифт — SF Pro и SF Pro Rounded, загруженные в файл.** Если
  в файле только Inter, подстановка **молчаливо врёт**: метрики
  расходятся достаточно, чтобы переполнения вылезли уже после
  перевода в код.
- **Текстовые стили именами iOS-ролей:** `Large Title`, `Title 1…3`,
  `Headline`, `Subheadline`, `Body`, `Callout`, `Footnote`,
  `Caption 1/2`. Суффикс `/Emphasized` = тот же стиль плюс вес.
  Это и даёт `.font(.body)` вместо `.system(size: 17)`, то есть
  **Dynamic Type бесплатно**.
- Префикс ведущего интерлиньяжа (`Tight Leading/Title 3`) — **не повод**
  уходить в `.system(size:)`: он меняет только line-height.

> **Граница, которую надо знать заранее: `AppFont` в Figma отобразить
> нельзя.** `Typography.swift:64` — это `TextStyleToken(size:weight:color:)`,
> композит **с цветом внутри**, а текстовый стиль Figma цвет не несёт.
> У каждого `AppFont` два конца: кегль с весом → текстовый стиль,
> цвет → отдельная привязка `TEXT_FILL`.

## 3. Семь обязательных срезов у каждого экрана

Шесть — из `Gamut/docs/16-фигма-как-источник.md`, седьмой добавлен
замером 08.10.2026.

1. **Тёмная и светлая — обе**, у каждого экрана.
2. **Increase Contrast** — хотя бы главный, настройки, пейволл.
3. **Крупный шрифт AX5** — там ломается всё, что задано фиксированной
   высотой.
4. **Три языка.** Французский длиннее русского примерно на треть.
5. **Ландшафт и iPad.**
6. **Пустое состояние у каждого экрана со списком.**
   > Экран без пустого состояния и без состояния ошибки в макете
   > превращается в экран без них в коде.
7. **Кадр с поднятой клавиатурой.** Высоту съедает то, что появляется
   только во время ввода; ни узкий экран, ни крупный кегль этого
   не ловят. Замер 08.10: поле «норма до» уходит под закреплённую
   кнопку. **Таких кадров у нас нет ни одного.**

### Восьмого среза нет — есть вопрос, который задают кадру

Замер 14.10.2026, и он про другую беду, чем все семь выше.

Дефект экрана «Семья» — объяснение, как позвать человека, и строка
«Общий дневник · выключен» уходят под закреплённую кнопку — лежал
**на четырёх кадрах за месяц**. Кадры снимали, в журнал приёмки
клали, каждый из них кто-то открывал. Ни один не спросил про низ
экрана: смотрели на шапку, на контраст подписи, на тему.

> **Поверхность без кадра лечится переделкой входа. Поверхность
> с кадром, но без вопроса, не лечится ничем — она выглядит
> проверенной.**
>
> Кадр существует, когда на него посмотрели. Но смотрят всегда
> на что-то одно, и остальное на том же кадре остаётся невидимым
> ровно так же, как если бы его не снимали.

Отсюда требование не к съёмке, а к приёмке: **у каждого кадра
заранее назван список того, что на нём проверяют**, и он шире
того, ради чего кадр снимали. Минимум на всякий экран с закреплённым
низом — три вопроса:

1. не обрезан ли последний блок содержимого кнопкой;
2. виден ли **орган управления** (переключатель, ссылка, строка
   состояния), а не только текст про него;
3. виден ли список целиком — на крупном кегле под кнопку уходят
   уже не объяснения, а участники.

И ловушка приёмки, оплаченная трижды за один день: **имя файла
кадра — такой же ярлык, как строка вывода, его печатает человек.**
Восемь кадров в журнале лежат байт-в-байт одинаковыми парами, один
под именем «ДЕФЕКТ», другой под нейтральным. Имя обязано нести
**коммит, починку и исход** — `семья-низ-f0bda5c-ПОСЛЕ-3a72afc-ДЕФЕКТ-ЖИВ.png`,
а не `06-family-light.png`.

И тема кадра именем не доказывается: положение симулятора
(`appearance`, `increase_contrast`, `content_size`) **переживает
сессию, которая его завела**. Читать обратно до и после съёмки,
прочитанное писать рядом с кадром.

## 4. Чего в Figma быть не должно

- **Цветов контента** — данные человека, не бренд. Им место примерами
  на макетах, а не переменными темы.
- **Фрейма, названного `Sheet`/`Modal`/`Popover`, нарисованного
  встроенным подвидом.** Имя кодирует презентацию, и код обязан
  прочесть его как `.sheet` — иначе получится вид внутри вида.
- **Хромировки устройства** (`StatusBar`, `Bezel`, `HomeIndicator`)
  как части приложения: это шаблон мокапа, он выбрасывается.

## 5. Порядок приёмки макета в код

1. **`create_session(fileKey, description)`** — обязателен до любого
   файлового инструмента, **включая чтение**. Возвращает UUID, его
   передавать как `sessionId` дальше.
2. Скилл **`figma:figma-design-to-code`** — объявлен обязательным
   перед `get_design_context`.
3. **`get_design_context(fileKey, nodeId, clientLanguages: "swift",
   clientFrameworks: "swiftui")`** — главный. Даёт разом референс,
   кадр, имена SF Symbols и пути токенов.
   > `get_screenshot` **заменой не является**: имена символов и точный
   > текст подписей по кадру не восстанавливаются.
4. **`get_variable_defs(fileKey, nodeId)`** — какие переменные стоят
   на узле. Если переменные на макете есть, маппинг механический,
   а не на глаз.
5. **`search_design_system`** — прежде чем писать новое, проверить
   готовое. `queries` — массив **объектов**, не строк.

Приоритет подсказок, ранние перебивают поздние: Code Connect →
документация компонента → аннотации → токены → сырой hex и абсолютные
координаты.

Ассеты: `img*` URL живут **около семи дней** — в коммит кладутся
**байты**, а не ссылка.

## 6. Грабли, названные поимённо

- **React+Tailwind из `get_design_context` — референс, а не исходник.**
  Hex в `var(--labels/secondary, rgba(…))` это **fallback**, цель
  маппинга — путь токена. Перетащишь hex — потеряешь тёмную тему
  и Dynamic Type **молча**.
- **«You currently have nothing selected» — негодная цель, а не отказ
  доступа.** `node-id` указывает на страницу, не на фрейм. Лечится
  `get_metadata` → найти верхний фрейм → повторить. Это ровно наш класс
  «инструмент отвечает про себя, а не про мир».
- **Системный контрол, пересобранный из примитивов, выглядит так же
  и теряет всё** — доступность, RTL, Dynamic Type, тёмную тему,
  гаптику, motion-reduction. `.pickerStyle(.segmented)` против
  `HStack` + `Capsule`; `List`/`Form` против `VStack` + `Divider` —
  названо самым частым промахом.
- **`.padding(16)`, перенесённый из `px-4`, двоит отступ.** `List`,
  `Form`, `NavigationStack`, `ToolbarItem` и safe area уже вставляют
  платформенный инсет; ~16 pt у края экрана — это он и есть.
- **`.glassEffect()` на обычном контроле — двойной материал.** Система
  рисует стекло у `Button`, `TabView` и `.toolbar` сама.
- **Кастомный цвет Figma не кладётся в `AccentColor`**, если его имя
  ограничено компонентом (`--status/active`): `AccentColor` перекрасит
  **каждую** системную кнопку, тумблер и ссылку в приложении.
- **Кастомный шрифт — `.custom(_:size:relativeTo:)`**, не
  `.custom(_:size:)`: вторая форма убивает Dynamic Type.

## 7. Приёмка этого документа

**Не чтением.** Взять один существующий экран, завести его в Figma
по этим правилам и прогнать через `get_design_context`: если в выводе
**пути токенов, а не hex** — правила работают.

И одно, что надо починить в нашем инструменте до первого экрана:

```
DesignTokens/ядро-дизайна/figma-plugin/code.js:36
  if (name.startsWith("color/")) return 'Color("' + … + '")';
```

`Color("fill.1")` — форма имени **ассет-каталога**, а цвет Togo живёт
`Color(Dyn(dark:light:darkHC:lightHC:))`; ассет-каталогом он не живёт
вовсе. То есть **iOS code syntax врёт ровно в том единственном месте,
которое читают в Dev Mode.**

Это та же форма, что уже оплачена: `generate_tokens.py:325` год отдавал
в Фигму `"modes": ["Light"]`, а под ярлыком уезжала тёмная палитра
целиком.

> **Ярлык, который печатает сам инструмент, не является его замером:**
> он печатается до работы и не зависит от её исхода. Приёмка берётся
> у того, что от работы зависит — `grep` по
> `TogoShared/Generated/Tokens.generated.swift`.
