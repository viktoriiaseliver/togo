# Дизайн Togo — где он живёт

Правда по макетам — в Figma, решение Виктории 08.10.2026. Правда
по токенам — в `DesignTokens/tokens.json`, и это **не одно и то же**;
почему — в конце файла.

> **Пока `fileKey` пуст, у приёмки макета нет адреса.** Это не
> формальность: `create_session(fileKey, …)` обязателен до любого
> обращения к файлу, включая чтение. Нет ключа — нет ни одного шага
> из `ТРЕБОВАНИЯ.md`.

Ключ берётся из URL: `figma.com/design/:fileKey/:name?node-id=1-2`.
У файла с ветками (`…/design/:fileKey/branch/:branchKey/…`) в аргумент
`fileKey` идёт **`branchKey`**, а не первый ключ — иначе читается
не та ветка, и расхождение выглядит как чужая правка макета.

### `CodeConnect/` — механизм без входа, и это названо нарочно

Пять файлов (`Banner`, `Button`, `Card`, `Chip`, `ListRow`) написаны
25.08.2026 и связывают компоненты Figma с типами `TGBanner`, `TGButton`,
`TGCard`, `TGChip`, `TGListRow`. Они **не входят в таргет приложения**
нарочно: их собирает CLI Figma вместе с пакетом `figma-swift`, и так
приложение остаётся без сторонних зависимостей.

Работать они не могут, и причин **две**, обе измерены:

```
figma.config.json   "<FIGMA_FILE>": "…/design/REPLACE_WITH_FILE_KEY/Togo"
каждый файл         figmaNodeUrl = "<FIGMA_FILE>?node-id=NODE_ID"
тариф               Code Connect требует Organization/Enterprise,
                    у нас Professional
```

> **Это заготовка, а не долг.** Зелёный модуль без места вызова значит
> две разные вещи, и снаружи они неразличимы: «не доделали» и «нельзя
> доделать». Здесь второе, и названо оно здесь, чтобы следующая сессия
> не пошла «подключать» то, что упирается в тариф.

Что снимет: ключ файла Figma в `figma.config.json` **и** переход
на Organization. Первого мало.

И граница, которую стоит знать до того, как тариф появится:
**Code Connect ставится только на свои компоненты.** У системных
(`Button`, `Toggle`, `List`, `Form`, `TabView`) уже есть первопартийные
маппинги, и перекрытие своим шаблоном делает вывод **хуже**. То есть
`TGButton` — да, системный `Toggle` — нет.

Рядом, но не здесь: `DesignTokens/ядро-дизайна/tokens/` — двенадцать
файлов CSS-ядра. Это **вход трёх живых инструментов**, а не справка:

```
TogoTests/SpacingGridTests.swift      → tokens/spacing.css
Tools/contrast_graphite.py            → tokens/colors.css, tokens/togo.css
Tools/сверка_токенов_с_фигмой.py      → tokens/figma-variables.json
```

И `DesignTokens/ядро-дизайна/figma-plugin/` — рабочий плагин, который
заводит в файл Figma 130 переменных со `scopes`, code syntax, текстовые
стили и наборы вариантов. Запускается из Figma:
**Plugins → Development → Import plugin from manifest…** Тариф для него
не нужен.

## Почему макеты в Figma, а токены — нет

Замер тарифа 12.10.2026:

| | Professional |
|---|---|
| Режимов на коллекцию | **4** |
| Code Connect | нет (нужен Organization) |
| REST `GET /v1/files/:key/variables/local` | нет (нужен Enterprise) |

У токенов Togo **ровно 4 режима темы** (`Dark · Light · Dark HC ·
Light HC`) **и ровно 4 режима акцента** (`Lime · Orange · Sky · Pink`).
Обе коллекции стоят в упор под потолком: пятый акцент или пятый режим
темы на этом тарифе **невозможны** — и узнать об этом лучше здесь,
чем на половине перерисовки.

Без REST к переменным код не может прочитать Figma. Значит направление
остаётся прежним:

```
tokens.json ──generate_tokens.py──→ Tokens.generated.swift
                                 ──→ tokens.css
                                 ──→ figma-variables.json ──плагин──→ Figma
```

> **Figma — копия токенов, а не их источник.** Её слово 08.10 — «правда
> будет в figma» — сказано про макеты: экраны, состояния, раскладку.
> Про цвет остаётся в силе `ИСТОЧНИКИ.md`: правка делается **только**
> в `tokens.json`, иначе не доедет ни до приложения, ни до Figma.

Когда тариф станет Organization, разворот возможен — и тогда у шва
появится конец, который **нельзя проверить по коммиту**: Figma живёт
вне git, как ASC и живые страницы сайта. Сторож контраста
(`contrast_graphite.py`, `InkContrastTests`) обязан остаться
**на стороне кода** и после разворота: Figma контраст не считает,
и правка цвета в ней перестала бы краснеть до того, как доедет
в `tokens.json`.

## История этой папки

Заведена 12.10.2026 вместе с уборкой. До неё дизайн жил в
`docs/design-handoff` (149 файлов) и `docs/design-system` (391),
плюс десять копий одной выгрузки в `.хранилище-вне-git/Togo/`.

Удалены из рабочего дерева коммитом — история git их хранит,
`git show <коммит>:<путь>`. Переселено **только то, у чего есть
читатель**, и читатель назван выше поимённо.

> **Уборка чуть не снесла вход живого инструмента, потому что каталог
> был назван по происхождению данных, а не по их роли.** Имя
> `design-handoff` читается как «пакет дизайна, который заменит Figma»;
> ничто в нём не говорило, что внутри лежит `spacing.css`, который
> читает тест. Новые имена — `ядро-дизайна`, `эталонные-кадры` —
> названы по роли.
