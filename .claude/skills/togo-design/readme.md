# Togo — дизайн-система «Лёд»

> **Сначала прочти [ИСТОЧНИКИ.md](ИСТОЧНИКИ.md).** Этот документ описывает
> систему, а не приложение: часть принята, часть нет, а один его раздел
> о словаре измерением опровергнут. Источник правды по цвету — `DesignTokens/tokens.json`.

Togo — дневник собаки на iOS: когда выводили, когда кормили, каким был стул. Названо в честь Того — вожака упряжки Сеппалы, который в 1925 году вёз сыворотку в Ном. Автор — Виктория Селіверстова.

Источники: папка «Togo-для-дизайнера» (снимки 12 экранов, tokens.json, DESIGN-SYSTEM.md, NAVIGATION.md, STATES.md, опись компонентов, исходники TG*-компонентов на SwiftUI). Репозиторий: `/Users/viktoriias/Projects/Togo`.

Светлая — по умолчанию (`:root`). Тёмная — `[data-theme="dark"]` на любом предке. Имена ролей одинаковые, меняются только значения: компоненты не знают, какая тема.

## CONTENT FUNDAMENTALS
- На «ты», без восторга и без восклицаний. «Сомневаешься — выводи.»
- Одна мысль — одна строка. Пояснения живут только в разделах (уровень 2), на главном их нет.
- Словарь: выход, занятие (не дрессировка), маркер, эпизод, доза, окно натощак, дежурный. «Прогулка» — отдельный режим, не синоним выхода. В интерфейсе нет слов «событие», «лог», «синхронизация», «ошибка», «данные».
- Заголовки разделов — обычным регистром, не капсом.
- Эмодзи не используются.
- Имя продукта — только латиницей: Togo.

## VISUAL FOUNDATIONS
- База: лёд (светлая) или ночь (тёмная), обе холодные. Без градиентов, текстур, иллюстраций. Фото собаки — единственная картинка.
- Цвет: синий — только интерактив и «сейчас». Хвойный — «сделано». Янтарь — только окно натощак. Красный — пропуск дозы, кровь, удаление. Смысл всегда несут цвет, значок и слово вместе: в Китае красный — удача, на Ближнем Востоке жёлтый связан с трауром, поэтому цвет один ничего не значит.
- Шрифт: SF Pro Rounded 800 для главной цифры, клички и заголовка экрана; SF Pro для всего остального. Арабский — SF Arabic Rounded, японский — Hiragino Maru Gothic. В вебе их заменяют Nunito и Noto Sans Arabic. Минимальный кегль 14.
- Форма: главное действие — капсула 60 pt. Второстепенные — стеклянные круги 44 pt. Карточки 20, плитки 18, шторки 40 с отступом 8 от краёв экрана (парят). Бордеров у карточек нет.
- Стекло: таббар, круглые кнопки, пауза. `--tg-glass` + blur 24 + внутренний край 1px. Больше нигде.
- Тени: одна плавающая (`--tg-shadow-float`) и одна у шторки. Карточки без тени.
- Движение: 120 / 180 / 280 мс, без пружин. Нажатие — действие темнеет (`--tg-action-pressed`), без сжатия.
- Раскладка: таббар — плавающая стеклянная капсула, док с главной кнопкой над ним. Режим прогулки занимает экран целиком, цели от 60 pt, главная — 104 pt.
- Плотность: уровень 0 (покой) — кличка, одна цифра, лента дня, одна кнопка и «+». Уровень 1 — шторка по тапу. Уровень 2 — раздел, где можно объяснять.
- RTL: зеркалятся лента, шевроны, «назад», значок шага. Цифры, часы, таймер и галочка не зеркалятся. Цифры по региону: 0–9 или ٠–٩.

## ICONOGRAPHY
- В макетах — Material Symbols Rounded с CDN (Google Fonts), вес 500, opsz 24. Заливка (FILL 1) только у активной вкладки, у сделанного в ленте и у сигналов.
- В приложении по правилам проекта — SF Symbols. Material здесь — замена для веба. Своих SVG нет, эмодзи и юникод-символы как иконки не используются.
- Основные: home, pets, calendar_month, group, medical_services, directions_walk, restaurant, medication, water_drop, hourglass_top, emergency, settings, add, close, check, chevron_right.
- Логотипа в материалах нет: там, где нужен знак, пишется «Togo» шрифтом.
