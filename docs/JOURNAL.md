# Журнал проекта

Не changelog. Changelog отвечает на вопрос «что изменилось в приложении»,
журнал — «что делали, почему именно так и что дальше». Через полгода
полезнее второе: решения забываются быстрее кода.

Новая запись заводится командой `make journal` — она создаёт файл за
сегодняшний день и вписывает его сюда.

- [2 сентября 2026](journal/2026-09-02.md) — ревизия трёх невыполненных обещаний и журнал действий
- [27 августа 2026](journal/2026-08-27.md) — свежие логи с телефона, молчащие напоминания, подготовка TestFlight
- [26 августа 2026](journal/2026-08-26.md) — вторая ревизия по эвристикам и правки по живому дневнику
- [25 августа 2026](journal/2026-08-25.md) — репозиторий с нуля, токены под Figma, экраны для App Store, питание и режим
