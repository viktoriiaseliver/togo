# Журнал проекта

Не changelog. Changelog отвечает на вопрос «что изменилось в приложении»,
журнал — «что делали, почему именно так и что дальше». Через полгода
полезнее второе: решения забываются быстрее кода.

Новая запись заводится командой `make journal` — она создаёт файл за
сегодняшний день и вписывает его сюда.
