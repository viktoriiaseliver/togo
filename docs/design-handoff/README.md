# Handoff: Togo — финальный чистовик всех экранов

## Overview
Togo — iOS-дневник собаки для семьи: прогулки, туалет, еда, лекарства по часам (натощак), запас, инциденты, работа с поведением. Этот пакет — финальный дизайн всех экранов приложения в одном стиле («Сегодня» T5+), со светлой и тёмной темой, iPhone SE, крупным шрифтом AX3, разворотом, iPad, виджетами, Live Activity, Watch и StandBy.

## About the Design Files
Файлы в пакете — **дизайн-референсы в HTML**: прототипы, показывающие вид и поведение. Это не продакшн-код. Задача — **воспроизвести их в SwiftUI** (iOS 26, Liquid Glass) по устоявшимся паттернам кодовой базы Togo. Инженерные правила проекта — в `SwiftUI.md`.

Открыть: `Togo ФИНАЛ.dc.html` в браузере рядом с `support.js` и `styles.css`. Каждый экран — рамка с атрибутом `data-screen-label` (= имя фрейма/вью) и `data-theme="dark|light"`.

## Fidelity
**High-fidelity.** Финальные цвета, типографика, отступы, тексты. Воспроизводить точно, значения — из токенов (`tokens/`), не из скриншотов.

## Сквозные правила
- Шрифт: SF Pro Text — текст; **SF Pro Rounded 300** — все числа-показания; единица (ч, мин, г, таб) — мелко, выровнена по верху числа, цветом `accent-text`.
- Иконки в макете — Material Symbols Rounded (wght 300) как заглушки; в приложении — **SF Symbols** с близким смыслом.
- Текст ≥ 13 pt, касание ≥ 44 pt. Строка ≤ 7 слов, одна мысль, сначала главное.
- Каждая кнопка — с иконкой. Одна главная кнопка 64 pt с «гранью» (тень снизу `edge-height` 4 pt цвета `accent-edge`), две второстепенные 52 pt (грань 3 pt `fill-edge`). Нажатие: кнопка опускается на высоту грани, 0.15 s, `.impact(.light)`.
- Цвет: лайм `accent` — главное действие, прогулка, количества; янтарь `status-warning` — только натощак (и «Срыв» в режиме поведения); терракот `status-error` — инцидент, тревога, запас ≤ 3 дней, удаление; оранжевый `stock-low` — запас ≤ 7 дней. Время — всегда нейтральное `text-secondary`.
- Темы: Dark по умолчанию, Light, + High Contrast для обеих (`data-contrast="high"`).

### 4 · История (вкладка 2)
День: навигация ‹ дата 📅, неделя 7 капсул (сегодня — `fill-inverse`, точка — день с инцидентом), заголовок-ответ 34 Rounded 300 «Спокойный день» + строка, исключение строкой `error-subtle`, 4 итога (иконка · название · сравнение с обычным · число Rounded), кнопка «День по часам».
**День по часам:** фильтр-капсулы (Всё/Туалет/Лечение/Инциденты), час — Rounded 20 слева, события строками ленты, пустые часы сжаты в «ничего · 14–18», натощак — янтарная капсула под дозой.

### 5 · Запас
Список карточек: имя · расход в день · остаток (число 44, цвет по уровню) · «хватит до» · 14 пилюль (1 = 1 день). Уровни: > 7 дней — `accent`; ≤ 7 — `stock-low`; ≤ 3 — `stock-out` (= `status-error`). Кнопка «Купил» (44, `accent`) — только при ≤ 7. Сортировка — что кончится раньше.
Карточка препарата: расписание (дробные дозы, ½ списывает 0,5), строки параметров с шевронами (в упаковке, утром/вечером, годен до, напомнить купить, можно дать на улице; для мл — флакон, за приём, курс до, вскрыт, после вскрытия). Курс короче запаса — о покупке не напоминаем.
**«Купил»:** степпер количества + чипы пресетов, «Годен до · с упаковки» (месяц + год), «Напомню за месяц до конца срока», переключатель «Сразу вскрыл» (запускает отсчёт после вскрытия), «Добавить в запас». Пополняет у всей семьи. Отмена тостом 5 с.

### 6 · Онбординг (3 шага)
Полоса прогресса 3 сегмента. 1 «Кто у вас?» — фото (позже), кличка, вес, дата рождения. 2 «Как живёт Стич?» — еда, лекарства по часам, туалет (чипы). 3 «Когда беспокоить?» — пример уведомлений: со звуком / тихо; «Разрешить» + «Не сейчас». Далее — «Сегодня» в состоянии 07.

### 7 · Профиль (вкладка 4 «Собака»)
Профиль: аватар, кличка, порода/возраст/вес; группа «про собаку» (Режимы, Лечение и запас, Питание, Уход и прививки), группа «про людей» (Семья, Уведомления, Если что-то случилось — красная иконка).
**Режимы:** переключатели «Лечение по часам», «Работа с поведением», чипы «Туалет: Улица/Пелёнка/Переходим», список препаратов + «Добавить препарат». Режимы меняют состав «Сегодня»; на главном не переключаются.
**Уведомления:** со звуком — доза в её час, доза не отмечена (через 15 мин), кровь или рвота у семьи; тихо — кто-то дал дозу, можно кормить, запас кончается, пора выйти; «Ночью тихо 23:00–6:30».
**Семья:** участники (роль, ситтер со сроком), «Сейчас со Стичем · Передать», «Пригласить». **Пригласить:** Семья/Ситтер/Врач, права (записывать, история, тревоги), «Доступ до», «Поделиться ссылкой» (24 ч).

### 8 · Правка и удаление
- Запись: свайп влево → «Изменить» (`fill-3`) и «Удалить» (`status-error`), по 88 pt; полный свайп удаляет. Тап → шторка: время, длительность, кто, заметка, чипы, «Удалить запись».
- Удаление записи — сразу, тост «Удалено · … / Отменить» с кольцом 5 с.
- С подтверждением (action sheet): препарат (+ мягкий выход «Только остановить курс»), участник семьи, собака (ввести кличку).
- Полная таблица «что / изменить / удалить / подтверждение» — в файле, раздел 8.

### 9 · Система
- **Экран блокировки:** Live Activity прогулки (таймер `accent-text`, «пописал · 1», «доза через 2 мин», кнопки «Пописал»/«Домой» — App Intents), уведомления: доза со звуком (Дал / После прогулки), «Мама дала дозу» тихо, запас (иконка `error-subtle`, Купил / Завтра).
- **Dynamic Island:** compact прогулка (кольцо `accent` + 13:04), compact натощак (кольцо `status-warning`, убывает за 30 мин, 0:19), minimal, expanded (таймер 44 + 2 кнопки).
- **Виджеты:** small — показание + главная кнопка по режиму туалета («Просится»/«Гулять»); small натощак — отсчёт до еды; medium — показание + «дальше» + 2 кнопки; medium «Запас» — пилюли по уровням.
- **Блокировка (accessory):** circular «2:10 гулял», rectangular «дальше · Доза в 20:00». **Watch:** показание + «Просится». **StandBy:** число 96 + «дальше / потом».
Системные поверхности не зависят от темы: `system-island` #000, `system-text` #F4F4F2, `system-text-2` #A3A39F, `system-fill` rgba(255,255,255,.12).

## Interactions & Behavior
- Записи пишутся одним тапом; уточнения необязательны. Тост «Записано · … / Отменить» 5 с (`toast-duration`).
- Цифры показания меняются `.contentTransition(.numericText())`, 0.3 s.
- «Дал дозу» мягко пульсирует 2 × 1 s только в час дозы; Reduce Motion — без пульса.
- Все переходы 0.15–0.3 s, `ease-out` cubic-bezier(.2,.8,.2,1); Reduce Motion — только прозрачность. Reduce Transparency — стекло заменяется `fill-1`/`fill-2`.
- Ошибки сети: запись сохраняется локально, строка «Нет сети · N записей не ушли», нейтральный тон.

## State Management
- `dog` (кличка, вес, фото), `modes` {treatment, behavior, toilet: street|pad|transition}.
- `entries[]` {id, type, time, duration?, amount?, unit?, tags[], authorId, editedBy?, synced}.
- `rhythm` (обучение 4 дня → ожидаемое время выхода), `nextUp` (выход / доза / еда / клиника при тревоге).
- `fastingWindow` {doseAt, until}; `alerts` (кровь, 3 рвоты, тишина мочи).
- `meds[]` {name, unit: tab|ml|dose, schedule[{time, qty}], courseEnd?, stock, packSize, expiry?, openedAt?, shelfAfterOpenDays?, giveOutside}; уровень запаса = остаток / дневной расход → ok | low (≤ 7) | out (≤ 3).
- `walk` (активная прогулка: startedAt, marks[]) → Live Activity.
- `family[]` {role, rights, accessUntil?}, `onDuty`.
- Состояние главного экрана выбирается по приоритету: тревога > на улице > час дозы > натощак > ситтер > первые дни > ночь > обычно; «нет сети» накладывается.
