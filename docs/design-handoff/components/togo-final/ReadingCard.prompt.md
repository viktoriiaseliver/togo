Карточка показания на «Сегодня»: сколько прошло, полоса до следующего события и строка «дальше»; сжимается при прокрутке ленты.

```jsx
<ReadingCard label="С прогулки" parts={[{ v: "2", u: "ч" }, { v: "10", u: "мин" }]}
  bar={{ pct: 62, from: "гулял в 7:28", to: "обычно до 11:00" }}
  next={{ icon: "directions_walk", title: "Выход около 11:00", short: "11:00", when: "через 1 ч 20" }}
  collapse={scrollTop / 150} />
```

- `tone`: default (единицы лаймом) · timer (на улице, число лаймом) · muted (ночь, первый день) · alarm (фон error-subtle, «дальше» = клиника, `next.tone="error"`).
- `bar.tone="warning"` — только окно натощак.
- Держите карточку ВНЕ скролл-контейнера ленты, иначе высота прыгает.
