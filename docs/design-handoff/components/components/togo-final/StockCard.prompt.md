Карточка запаса: сколько осталось, до какого дня хватит, 14 пилюль = 14 дней; цвет по уровню.

```jsx
<StockCard name="Левотироксин" perDay="1,5 таб. в день" left="4" unit="таб" until="сб 6 окт" daysLeft={2} status="Кончится в субботу" onBought={openBuySheet} />
```

- Уровень считается из `daysLeft`: > 7 — лайм, ≤ 7 — оранжевый `--stock-low`, ≤ 3 — красный `--stock-out`.
- «Купил» показывается только у low/out. Шторка «Купил» спрашивает количество и срок годности (можно пропустить), «Сразу вскрыл» — для капель.
- Заменяет `StockMeter` (у того полоса всегда акцентная).
