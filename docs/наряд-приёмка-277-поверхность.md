## Два условия, без которых любой замер ниже отвечает про неизвестное

**1. У архива должен быть назван коммит.** 277 собирается из
`git worktree` на названном коммите, не из рабочего дерева. Основание —
замер менеджера 14.10: в дереве лежала незакоммиченная правка, которая
**не компилировалась** (`FamilySync.swift:458`, `has no member
'isEmpty'`), и чистый `git status` за минуту до этого ничего не значил.

**2. Замер с Debug на архив не переносится.** Осмотр бандла 14.10 снят
на Debug для симулятора. Про `en.lproj` у нас измерено, что он
появлялся **в одной сборке из четырёх одного кода**, и догадка «чистая
против инкрементальной» опровергнута третьей.

> `Bundle.main.localizations` не одинаков у разных сборок одного кода,
> и предсказать этого мы не умеем.

## 2. Кадр экрана «Семья» на 277 — ПЕРЕМЕРИТЬ

Кадр `0ee811b`
(`Дизайн/кадры-приёмки/журнал-приёмки/семья-низ-f0bda5c-ПОСЛЕ-3a72afc-ДЕФЕКТ-ЖИВ.png`)
доказал на `f0bda5c`, что починка `3a72afc` до этого экрана **не
дошла**:

```
«Приглашение уходит через общий дневник —»   ОБРЕЗАНО кнопкой
«Общий дневник · выключен ›»                 УХОДИТ ПОД ТАББАР
[ Добавить человека ]                        закреплён, подложки нет
```

Пока общий дневник выключен, приглашение не уходит вовсе
(`FamilyScreen.swift:193`). Человек, пришедший звать маму, видит одну
заметную кнопку, жмёт её — и заводит участника **без приглашения**.

С тех пор легло больше сотни коммитов. **Это единственная дверь к маме,
и её состояние надо знать до раздачи, а не после.**

Как снять, чтобы кадр был кадром:

```
прогон   xcodebuild test -only-testing:TogoUITests/ScreenshotTests
         класс латиницей — имя метода кириллицей -only-testing не берёт
кадр     06-family из своего .xcresult, Tools/extract_screenshots.sh
         имена в выгрузке UUID — сопоставлять по manifest.json
тема     simctl ui <udid> appearance|increase_contrast|content_size
         ставить И ЧИТАТЬ ОБРАТНО: команда постановки возвращает ПУСТО
третий   Tools/замер-кадра.py — средняя яркость PNG
свидетель
вынос    в Дизайн/кадры-приёмки/ ДО сноса стенда
```

**Признак зелени зависит от того, на чём написан набор.** У этого
UI-набора (XCTest) итог — `Executed 12 tests, with 0 failures`. Строки
`Test run with …` в его логе **нет ни одной**, и это не срыв;
`Makefile:90` описывает модульный набор на Swift Testing и для этого
прогона говорит обратное.

> **Мама увидит «Сегодня дежурит Мама · напоминания идут ЕМУ»
> в первый же день дежурства.** Если это уезжает в 277 — заметки
> говорят прямо, а не умалчивают.

снимки здорового продукта.
