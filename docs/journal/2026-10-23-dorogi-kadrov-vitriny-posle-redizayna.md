## Почему именно так

**Зонд, а не чтение исходников.** Прежняя сессия записала про
`шапка-меню`: «зонд дал `PopUpButton`, и по тапу иерархия
не менялась». Оба утверждения сняты замером, и **контроль стоял
в той же команде, что и предмет**:

```
buttons[«шапка-меню»].exists      true,  elementType = 9 (.button)
popUpButtons[«шапка-меню»].exists false                  ← контроль
кнопок до тапа                    19
кнопок после тапа                 21: + «Настройки», + «Другой день»
```

Дороги вышли такие:

```
Настройки   «…» (шапка-меню) → «Настройки»
Семья       вкладка собаки (ПО ПОРЯДКУ, имя вкладки = кличка)
            → строка «Семья и дежурство»; второй вход — «…» → «Семья»
Запись      круглая «+» (`низ-записать`) → Инцидент · Стул · Еда · Ещё
Занятие     «+» → «Ещё» → «Занятие · N мин»
Листалка    «…» → «Другой день» → «Предыдущий день»
```

**`app.sheets.count = 0` при поднятой шторке** — ограничить запрос
контейнером нельзя, такого элемента нет вовсе. Попытка «сделать
правильнее» дала бы ложный ноль. Вместо этого замерен **порядок**:
строки шторки стоят индексами 1–4, содержимое «Сегодня» — с пятого,
то есть `BEGINSWITH` + `firstMatch` берёт шторку, а не план дня.

## Открытые вопросы

- **Заготовки навыков: два хранилища под одним решением.**
  `ProcedureSkill` лежит в SwiftData (под `-UITesting` — **в памяти**,
  стирается каждый запуск), а флаг «уже подставлены» —
  `@AppStorage("procedureSkills.seeded")`, то есть UserDefaults,
  и он переживает всё. Замер в симуляторе:
  `"procedureSkills.seeded" => true` при пустом списке.

  > **Тест `testНавыкПопытка` зеленел РОВНО ОДИН РАЗ на симулятор.**
  > 17:16 зелёный, 17:5x и 17:40 красный, код теста не менялся.

  Человеку то же достаётся не в тестах: «удалить все данные»
  и восстановление из копии дают ту же пару — база чистая, флаг
  старый. **Хозяина у решения «заготовки подставляются один раз»
  тест назначить не может.** Тест теперь идёт настоящим путём
  человека — жмёт «Вернуть заготовки» — и печатает в лог, что
  заготовок не было.

- **`12-walk-mode`: тап, которого не было.** XCUITest посчитал
  «Пописал» недостижимым (`hit point {-1, -1}`) и **молча не нажал**.
  Кадр говорит «Пописал · 1», сценарий говорит «два». Тест зелёный,
  потому что счёт он не проверяет. Это не дорога и не вёрстка —
  это отсутствующая ось у теста.
