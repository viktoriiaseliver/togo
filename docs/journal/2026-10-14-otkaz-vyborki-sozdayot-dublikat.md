## Почему именно так

### Пункт наряда «поставить `@Attribute(.unique)`» — не работа, а невозможность

Первым шагом полагается проверить, что пункты ещё нужны. Этот
не нужен и не может стать нужным:

```
@Attribute(.unique) в продуктовом коде          0 вхождений
единственное упоминание  доккомментарий теста SharedDogTests:255
Persistence.swift:211-214  cloudKitDatabase: .private(…)
```

Хранилище зеркалится в CloudKit, а зеркало уникальных ограничений
не допускает. Значит от дубликата защищает **ровно одно** — выборка
по `id` в коде приёма. Проект это знал и записал тестом, а не
комментарием (`SharedDogTests:253-290`): «хранилище не склеивает двух
собак с одним `id` — это делает наш код».

### Эта защита обёрнута в `try?` во всех двадцати семи местах

```
выборок вида #Predicate { $0.id == id } в TogoShared/Sync   27
из них под try?                                             27
форм с разбором ошибки                                       0
```

Два способа сошлись: `git grep -c` по файлам даёт 12 + 15; счёт строк
с `try?` в контексте `-B1` даёт 27.

```swift
let existing = try? context.fetch(
    FetchDescriptor<Dog>(predicate: #Predicate { $0.id == id })
).first

guard let local = existing else {
    let dog = Dog(name: payload.name, weightKg: payload.weightKg)
    dog.id = payload.id          // ← тот же id, НОВАЯ строка
    context.insert(dog)
```

`try?` превращает отказ выборки в `nil`, то есть в «такой собаки нет».
Ответ кода на «нет» — завести новую.

> **Несостоявшийся замер здесь не молчит — он создаёт дубликат.
> Отказ падает не в безопасную сторону, а ровно в ту, от которой
> стоит защита.**

Что делает находку адресной, а не придиркой к стилю, — **асимметрия**:
у записи проект этот класс закрыл нарочно (`Persist.swift:48`,
`persist(otherwise:)`, и она же вызвана строкой ниже, в `:691`),
а у чтения соглашения нет вовсе. И цена промаха у чтения выше:
несохранённая запись теряется, несостоявшаяся выборка — размножается.

Проект уже снимал ровно этот `try?` однажды.
`SharedDiaryFetchFailureTests` заведён 24.09 после двух суток пустого
экрана у второго человека: «в `fetchNow` стояло `try?`, ошибка уходила
в никуда». **Класс закрыт в одном вызове из двадцати восьми.**

Доложив менеджеру «27 выборок, и это защита от дубля», я был прав
в половине:

```
SharedDiaryPayloads.swift   15   ОПОЗНАТЬ-ИЛИ-ВСТАВИТЬ

Ущерб разный, и сводить его в одно число значило бы предъявить счёт,

### Девятикратность: форма сошлась впервые, механизм НЕ установлен

Замер 09.10 по журналу с её телефона: девять строк под одним `id`.
Записано было «ни один локальный путь этого не даёт, остаётся
зеркало». Перепроверено на `14b2bca`:

| путь | даёт N строк под ОДНИМ id | чем измерено |
|---|---|---|
| онбординг | нет — свой `UUID()` | `OnboardingFlow:174-175` |
| прогрев схемы | нет — свой `UUID`, кличка непустая | `CloudKitSchemaWarmup:106` |
| архив | нет — переносит `event.id`, `dog.id` не трогает | `Backup:620` |
| **приём при отказе выборки** | **да** | `SharedDiaryPayloads:684-690` |

Это первый локальный путь, дающий ровно наблюдавшуюся форму. **Но
что сработал именно он — не установлено**, и различителя не было
никогда: записи в лог на ветке отказа нет, потому что ветки нет.
`try?` её не оставляет.

> Улика, которая ответила бы на вопрос, не писалась ни разу — и это
> то же самое свойство кода, которое вопрос породило.

Зеркало как источник строк не снято и этому кандидату не противоречит.

### Починка пуша встала не туда, куда её ставил план, и замер это перевернул

План предписывал звать `ReminderScheduler.cancelDose` на приёме чужой
отметки. **Не собралось бы:**

```
project.pbxproj   TogoShared входит синхронизированной группой
                  В ОБА таргета — Togo и TogoWidgetsExtension
                  исключений членства                        0
ReminderScheduler лежит в Togo/Store/ — только приложение
```

Ось пришлось переделать, и она вышла лучше заказанной: **«приехала
чужая отметка» — одно событие из нескольких, а «доза больше не ждёт» —
состояние**, и оно покрывает разом чужую отметку, восстановление
из архива, отмену схемы, паузу и выключенное лечение. Этого списка
никто не писал, он следует из условия.

Замер, с которого всё началось: `cancelDose` во всём проекте имел
**один** вызов — `DayPlanActions:286`, своя рука. То есть снять
напоминание мог только тот человек, который и отмечал дозу.

## Чужие замеры, которые сильнее моих, и я это говорю прямо

`togo-russian-testflight-qa` померила **контейнер**, а не код:

```

существует в iCloud.app.togo.diary     5   (prod И dev одинаково)
нет вовсе   WeightEntry · Clinic · DogDocument · LabResult ·
            VetVisit · Diagnosis · Prescription

Я весь день мерил, **правильно ли собирается нагрузка**. Она померила,
**есть ли куда её класть.** У мамы не будет ни взвешиваний, ни визитов,
ни анализов, ни диагнозов, ни назначений, ни документов — независимо
от того, что у нас в нагрузке. Мой `massPerUnitMcg` на этом фоне —
поле у типа, который хотя бы существует.

И развилка, которую она же нашла и которую я перечитал своими глазами
(`SharedDiaryOutbox.swift:56-74`):

```
.unknownItem      forget(id) + обратно в очередь → при отсутствующем
                  ТИПЕ условие не исчезает → ВЕЧНЫЙ КРУГ
.invalidArguments в switch его нет → default: continue → потеря навсегда
обе ветки         log.notice, state НЕ меняется — человеку не сказано
                  ничего ни баннером, ни значком, ни строкой
```

> **Ось `retries` построена на предположении, что отказ относится
> к ЗАПИСИ. Отказ, относящийся к ТИПУ, она мерит той же меркой.**

Какой код CloudKit отдаёт на запись несуществующего типа — **не
измерено**, и измеряется одним живым заходом с вошедшего iCloud,
которого у нас нет.
