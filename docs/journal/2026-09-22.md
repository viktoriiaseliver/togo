## Что сделали

- **Числа и окончания.** Тринадцать мест склеивали число со словом без
  `Fmt.plural`: «откладывали 5 раза», «1 записей», «2 дней подряд»,
  «Начать занятие · 5 минуты», «3 раз из 4». Добавлены `Fmt.minutes`,
  `Fmt.times`, `Fmt.records`, `Fmt.actions`; все места переведены на них.
- **Голос.** Четыре «вы»-глагола в «ты»-приложении: «начните», «Закройте
  и откройте», «Позовите», «Задержитесь». Остальные 2460 строк по
  словарю чистые: ни усилителей, ни канцелярита, ни «еще», ни дефисов
  вместо тире — это заслуга вчерашних проходов, не сегодняшнего.
- **Словарь.** «между событиями» → «между записями», «синхронизация
  iCloud» → «включён iCloud», «одно событие» → «записаны как одно целое»,
  «Это не ошибка» → «Так бывает», «данных N дней» → «записей всего за
  N дней», «роль позволяет» → «с твоей ролью можно». Правовой текст
  задет двумя фразами — отпечаток сайта обновлён, английская копия
  поправлена в одном слове.
- **Проход копирайтером по длинным строкам.** 109 строк длиннее 120
  знаков перечитаны; 23 сокращены без потери «почему»: преамбулы
  («На экране … видно» → «… показывает»), сдвоенные предложения слиты,
  «со-владелец» → «совладелец», «поднимает запись в терракот» →
  «красит в тревожный цвет» (терракот — слово дизайнера, не хозяина),
  «записи не уходят на наши серверы» → «серверов у нас нет» (первое
  подразумевало, что серверы есть). Защищённые формулировки — «не
  наказывай», «не брал еду», «непонятно», оценка занятия, дисклеймер —
  не тронуты.
- README больше не называет число ключей каталога: оно менялось трижды
  за сутки и всегда врало.

- **Ревью командой из десяти ролей** по копии репозитория — отчёт в
  Claude Doc (ссылка в `СТАТУС.md`). Главное: общий дневник не работает
  ни в одном звене (приём приглашения, зона гостя, `recordChangeTag`,
  поиск препарата), три молчаливых потери данных, политика врёт про
  приглашения. Шесть мелких правок внесены сразу, крупные — в план.

## Почему именно так

- Окончания — не мелочь: «5 раза» читается как ошибка приложения, и
  доверие к цифрам рядом («5 из 7 доз») падает вместе с ним.
- Слово «данные» в разделе «Данные и приватность» не тронуто: оно стоит
  в docs, в `review_notes`, в правовых текстах и в привычке iOS. Менять —
  только целиком и по решению заказчицы.
