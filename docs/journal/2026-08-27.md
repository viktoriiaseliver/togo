## Новый конфликт: шесть напоминаний молчали

В уходе заведено девять дел. Работают два.

У «раз в N дней» нет точки отсчёта, пока дело ни разу не отмечали:
`dueDate` возвращает пусто, и дело не становится сроком никогда.
У прививки то же самое без назначенной даты. Итого шесть дел из девяти
выглядят настроенными и не напоминают ни о чём.

Механизм починки был — карточка «нужна дата» на экране ухода. Но узнать
о ней можно было, только зайдя туда самому: на главном экране ничего
об этом не говорилось, а после переезда ухода в режим дня — тем более,
потому что молчащие дела в план дня не попадают по определению.

Теперь в конце режима дня стоит строка «6 напоминаний ждут даты»,
и тап ведёт туда, где дату ставят.

## TestFlight: что удалось и что нет

Ключ API работает, Issuer ID принят. Через API проверено:

* Team ID — `L7CPH7W5QW`, команда «Viktoriia Seliverstova»;
* идентификаторы `app.togo.diary` и `app.togo.diary.widgets` заведены;
* возможности у них включены: App Groups, iCloud, Push, покупки.

Дальше упёрлось в две вещи, которых через API сделать нельзя.

**Группа и контейнер iCloud не созданы.** Возможности включены, но самих
`group.app.togo.diary` и `iCloud.app.togo.diary` в портале нет, поэтому
профиль подписи их не содержит и сборка падает до компиляции. App Groups
и контейнеры iCloud App Store Connect API не отдаёт вовсе — только
портал.

**Записи приложения нет.** Экспорт доходит до конца и падает на
`missingApp(bundleId: "app.togo.diary")`. Создание приложения API
запрещает прямо: `The resource 'apps' does not allow 'CREATE'`.

Что сделано, чтобы не упираться в это дважды: скрипт загрузки сам берёт
Team ID из конфигурации, ключ — из `~/.appstoreconnect/private_keys/`,
Key ID — из имени файла. Руками остаётся Issuer ID. Появился режим
`WITHOUT_ICLOUD=1`: собирает без общей группы и iCloud, чтобы не ждать
портала. Приложение в нём работает целиком, только дневник не
синхронизируется между устройствами — ровно так же, как сейчас
на телефоне.

Проверено, что в этом режиме архив собирается и подписывается.
