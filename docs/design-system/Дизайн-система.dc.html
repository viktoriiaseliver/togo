Правила
Глубина = ступень серого. Каждый следующий слой светлее на одну ступень: bg → fill.1 → fill.2 → fill.3. Вложенный элемент не может быть того же цвета, что родитель.
Лайм = состояние. Заливка лаймом только у включённого элемента или у одного главного действия на экране. Лаймовый текст — статус «в порядке» и значение-показатель.
Один inverse на экран. Светлая карточка притягивает взгляд сильнее лайма, поэтому она одна и отдана самому срочному объекту.

Increase Contrast. Каждый fill поднимается на ступень, text.secondary → gray.200, у карточек появляется обводка 1 pt gray.600.
Состояние не только цветом. Включённый тумблер — ручка справа; статус-чип — слово рядом с цветом; ошибка — текст под полем.
Цифры для VoiceOver. «54 процента влажности», а не «54 %». Единица и подпись склеиваются в одну метку.
