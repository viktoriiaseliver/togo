9 · Перенос в Figma

Порядок 1. Запустить плагин из папки figma-plugin — он создаёт переменные Theme (Dark/Light), стили текста и компоненты Button, Chip, ListRow, TabBar, Toast. 2. Импортировать эту страницу плагином html.to.design (ссылку дам по просьбе, живёт 10 минут). Каждый экран придёт фреймом 390 × 844; подпись над ним — имя фрейма. 3. Выделить фреймы темы → Find and replace colors / плагин «Swap to variables»: hex → переменная по таблице справа. 4. Заменить кнопки и строки на инстансы компонентов; главную 64 — как Button / XL / Primary с новым свойством Edge. 5. Светлая тема: не дублировать фреймы, а переключить Mode у копии на Light — фреймы Light здесь для сверки.
Как устроены макеты Только flex с gap — после импорта это Auto Layout. Абсолютное позиционирование — только шкала дня и шторки над подложкой. Отступы на сетке 4: поля 20, между блоками 12/16, высоты 44 · 52 · 56 · 64 · 72. Радиусы: кнопка 16–18, плитка 14–16, шторка 28, чип 10–12. Текст: SF Pro, 11 · 13 · 15 · 17 · 21 · 24 · 34 · 96; цифры — табличные. Нижняя грань кнопки — тень 0 3–4 px без размытия цвета «edge».
