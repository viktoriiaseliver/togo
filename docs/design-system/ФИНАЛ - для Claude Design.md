# Togo — ФИНАЛ для Claude Design

Источник: `Togo ФИНАЛ.dc.html`. Все экраны в одном файле, стиль «Сегодня» T5+.
Стили — только токены из `styles.css` (→ `tokens/*.css`), тема через `data-theme="dark|light"` на рамке экрана.
Токены для Figma: `tokens/figma-variables.json`, `tokens/tokens.dtcg.json` (4 режима: Dark, Light, Dark HC, Light HC).

## Разделы и экраны
Каждый экран — рамка с `data-screen-label` = имя фрейма.

1. **Сегодня** — 10 состояний (Dark), 01/03/05 (Light), SE 375, AX3. Лента прокручивается, карточка сжимается.
2. **На улице** — режим поведения, без режима поведения.
3. **Шторки и итоги** — Просится (вердикт), Записать… (Dark/Light), Инцидент, Вырвал · Другое…, итог со срывом, «Как сходил?».
4. **История** — день (Dark/Light), день по часам.
5. **Запас** — список, Левотироксин, Капли Вет, «Купил» со сроком годности.
6. **Онбординг** — Собака, Режим, Уведомления.
7. **Профиль** — профиль, Режимы, Уведомления, Семья, Пригласить.
8. **Правка и удаление** — свайп, шторка правки, тост «Отменить», подтверждение + таблица «что где правится».
9. **Система** — блокировка + Live Activity + уведомления, Dynamic Island, виджеты, блокировка/Watch/StandBy.
10. **Разворот 874×402, iPad 1194×834.**

## Компоненты (собрать как Figma-компоненты)
- **Карточка показания** — подпись с иконкой · число SF Pro Rounded 300 + единица мелко сверху акцентом · полоса до следующего · строка «дальше» (кружок 40 + заголовок + время). Свёрнутая: число 34 + «дальше» справа.
- **Строка ленты** — кружок-иконка 32 (тон: лайм-подложка для улицы, error для инцидента, warning для срыва, fill-2 для остального) · заголовок 16 · подстрока 13: количество акцентом + «· кто» · время справа. Линия 2 px между кружками.
- **Строка состояния** — иконка 20 + текст 16 semibold цвета тона, опц. кнопка-капсула 44 справа. Без подложки.
- **Кнопки** — главная 64 (accent, грань `--edge-height`), второстепенные 52 (fill-2, грань `--edge-height-s`), у каждой иконка 20–24. Слайдер «Домой» 64.
- **Таб-бар** — стекло, активная вкладка с подписью.
- **Шторка** — стекло, радиус `--radius-sheet-floating`, ручка 36×5, шапка 44 · заголовок · 44.
- **Чип** — 44, выбран: accent-subtle + галочка; «Другое…» — контур accent-text.
- **Строка настроек** — кружок 36 · заголовок · подстрока · значение / переключатель / шеврон.
- **Пилюли запаса** — 14 сегментов, цвет по уровню.
- **Тост** — стекло, «Отменить» с кольцом 5 с.

## Цвет — правила
- Лайм `--accent` — главное действие, прогулка, количество.
- Янтарь `--status-warning` — только натощак (и срыв в режиме поведения).
- Терракот `--status-error` — инцидент, тревога, запас ≤ 3 дней, удаление.
- Оранжевый `--stock-low` — запас ≤ 7 дней.
- Время — нейтральное, `--text-secondary`.

## Тексты
Строка ≤ 7 слов, одна мысль, сначала главное. Текст от 13 pt, касание от 44.
