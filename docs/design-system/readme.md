# Graphite — дизайн-система Togo (iOS)

> Общее ядро Graphite для любых приложений — `GRAPHITE.md` и `Graphite - дизайн-система.dc.html`. Этот файл — продуктовый слой Togo поверх ядра.

Атомная дизайн-система iOS-приложения «Togo» — дневника собаки. Визуальный язык выведен из референса `uploads/original-…webp`: графитовые плашки, один яркий акцент, крупные тонкие цифры.

Это чистовик. Источник правды — файлы в `tokens/` и `components/`. Эталон экранов — `Togo ФИНАЛ.dc.html` (все экраны, стиль «Сегодня» T5+, 15 разделов: в т.ч. дрессировка, поездки, течка, уход, экстренный, ветсводка, ситтер, подписка, настройки), интерактивная сборка — `ui_kits/togo-final/`, пакет для разработки — `design_handoff_togo_final/`. `Дизайн-система.dc.html` (v1), `Дизайн-система v2.dc.html`, `Togo Палитры.dc.html`, `Togo Стиль из референса.dc.html` — история исследования, на них не опираться.

## Быстрый старт нового проекта

Для нового приложения — `GRAPHITE.md`, раздел «Новое приложение». Ниже — как было для Togo.

1. Скопируйте `graphite.css`, `tokens/`, `components/` и `starter/` в новый проект. В Figma импортируйте `tokens/figma-variables.json` (или `tokens.dtcg.json` через Tokens Studio).
2. В `starter/brand.css` задайте один акцент (заливка и текст для тёмной и светлой темы). Либо `data-accent="orange|sky|pink"` на `<html>`.
3. `starter/settings-profile.html` — готовые экраны «Настройки» и «Профиль». `starter/screen.html`: экран 390 pt с NavBar, Card + CardHeader + ActionRow, SectionHeader + ListRow, Toast, TabBar. Это шаблон — собирайте из него.
4. Тема — `data-theme="light"`, повышенный контраст — `data-contrast="high"` на `<html>`.
5. Предметные компоненты (`togo*`) берите как образец: каждый собран из Card, CardHeader, ListRow, ActionRow, Button, ChoiceChips, SelectCircle.

На экран: одна primary-кнопка, остальные secondary / plain. Проверка — 320 pt + AX1, светлая и тёмная.

## Аудит

`AUDIT.md` — проверка контраста (528 пар × 4 режима × 4 акцента), различимости статусов, иерархии поверхностей, названий, состояний и масштабирования. Повторять после любого изменения цвета.

## Структура

Токены → атомы → молекулы → организмы → компоненты Togo. Компонент ссылается только на семантические токены (`--fill-1`, `--accent-text`), никогда на hex. В SwiftUI это Asset Catalog с вариантами Any / Dark / High Contrast и `Color("accent")`.

- `graphite.css` — ядро, только `@import`. `styles.css` — Togo: ядро + `tokens/togo.css`.
- `tokens/system.css` — системные поверхности iOS (`--system-*`).
- `tokens/colors.css` — тёмная тема по умолчанию, `data-theme="light"`, `data-contrast="high"`.
- `tokens/accents.css` — `data-accent="orange|sky|pink"`; лайм по умолчанию.
- `tokens/togo.css` — статусы Togo: `--status-done`, `--status-waiting` (окно натощак), `--status-overdue`; запас `--stock-low`, `--stock-out`.
- `tokens/typography.css`, `spacing.css`, `motion.css`, `icons.css`, `base.css`.
- `guidelines/` — карточки основ: цвета, текст, цифры, отступы, радиусы, размеры, тени, стекло, иконки.

## Цвет

**Тёмная тема** — графит. page #050503, bg #181818, ступени fill #2C2C2C → #383838 → #454545. Вторичный текст #B2B2AE. Теней нет, глубина — ступенью светлее.

**Светлая тема v3** — тёплые нейтральные (холодно-сиреневые серые рядом с тёплым лаймом выглядели грязно). bg #F6F6F3, карточки белые, fill-2 #EFEFEB, fill-3 #E2E2DD, грань кнопок `fill-edge` #D9D9D3. Вторичный текст #5E5E59, неактивный #A3A39D. Стекло белее (rgba 255 .72), тени без синевы. Две тени: `elev-1` — карточки и строки, `elev-2` — плавающие элементы.

**Акцент** — один цвет на тему, остальное выводится из него:

| Токен | Назначение |
|---|---|
| `accent` | заливка главной кнопки, «включено», выбранное |
| `accent-pressed` | нажатие, на ступень темнее |
| `on-accent` | текст на заливке — всегда почти чёрный #0B0B0C |
| `accent-text` | акцентный текст и ссылки на фоне |
| `accent-subtle` / `accent-subtle-text` | пастельный бейдж и его текст |
| `accent-knob` | ручка тумблера на акценте |

Светлые значения (заливка · текст):
- лайм #C6EF4E · #3A6A00
- оранжевый #FF8A3D · #B04600
- небо #4FA9FF · #0A5EAE
- розовый #FF6FA3 · #B0285E

Заливки в светлой теме — чистые насыщенные средние тона, не пастель: на белом пастель выглядит выцветшей. Текст на заливке чёрный, от 7.5:1. Акцентный текст — тот же оттенок, затемнённый до 5–6.5:1 на белом.

**Статусы.** Ошибка и предупреждение появляются только в статусах и плашках, никогда как декор. Окно натощак — только янтарь (`--status-waiting`). Повышенный контраст поднимает `accent-text` до 7:1 и включает обводку.

**Запас** (`tokens/togo.css`): > 7 дней — лайм; ≤ 7 — оранжевый `--stock-low` (#FFA15C / #B85400); ≤ 3 — `--stock-out` = `status-error`. Цвет у цифры, «хватит до», пилюль, строки и виджета. «Купил» — только у оранжевого и красного.

**Где какой цвет:** лайм — главное действие, прогулка, количество; янтарь — натощак (и «Срыв» в режиме поведения); терракот — инцидент, тревога, запас ≤ 3, удаление; оранжевый — запас ≤ 7. Время всегда нейтральное.

## Типографика

SF Pro, только системные стили Dynamic Type. Заголовки regular 400, Headline 600. Цифры — SF Pro Rounded 300, табличные (44 / 56 / 80), растут не больше чем на 150 %. Минимум 12 px на любом размере. Основной текст 17, вторичный 13–15.

## Переменные (как в Figma)

`tokens/figma-variables.json` — коллекции и режимы Figma Variables; `tokens/tokens.dtcg.json` — тот же набор в формате W3C Design Tokens для Tokens Studio. Визуально — раздел «Переменные» в `Дизайн-система Togo.dc.html`.

| Коллекция | Режимы | Что внутри |
|---|---|---|
| Accent | Lime · Orange · Sky · Pink | `accent/dark/*`, `accent/light/*` — сырые значения акцента |
| Theme | Dark · Light · Dark HC · Light HC | `color/bg/*`, `color/fill/*`, `color/text/*`, `color/line/*`, `color/status/*`, `color/control/*`, `color/material/*`, `color/accent/*` (→ ссылка на Accent), `effect/elevation/*` |
| Togo | — | `color/togo/*` (→ на Theme), `color/system/*` |
| Spacing | — | `space/0 … space/64`, шаг 4 |
| Layout | — | `layout/gap-cards` → space/8, `gap-sections` → space/32, `margin-compact` → 16, `margin-regular` → 20, `pad-card` → 20, `pad-row` → 16, `pad-row-y` → 12, `pad-inner` → 12 |
| Radius · Size · Type · Motion | — | `radius/*`, `size/*`, `type/size/*`, `type/weight/*`, `motion/*` |

Имя CSS = имя Figma без группы: `color/fill/1` → `--fill-1`, `space/16` → `--space-16`, `layout/pad-card` → `--pad-card`. Перенос в SwiftUI — `SwiftUI.md`.

## Форма, отступы, движение

- **Радиусы:** шит 36, карточка 28, строка 24, вложенные 16. Всё ниже 64 pt — пилюля или круг. Вложенный радиус = внешний − padding.
- **Отступы — только шаг 4:** `space/4, 8, 12 … 64`. Других значений в компонентах и макетах нет (проверено по всем файлам). Между карточками и строками 8, между секциями 32, поле карточки 20, строки 16 × 12. Поля экрана 16 (320–374 pt) и 20 (от 375). Единственное исключение — толщина линий и полос 1–2 px.
- **Цели касания** от 44 pt, основные действия 52, быстрая запись 104.
- **Стекло** — только плавающее: таб-бар, тост, меню, пуш. Блюр 20; при Reduce Transparency — fill-2.
- **Нажатие:** масштаб 0.96 (круглые 0.94), 0.15 s, заливка на ступень темнее. Hover не оформляется.
- **Движение:** `.snappy`, ease-out cubic-bezier(.2,.8,.2,1), 0.3 s. Цифры — `.numericText`. Reduce Motion — только прозрачность.
- **Хаптика:** `.selection` — тумблер и сегмент; `.impact(.light)` — порог свайпа; `.warning` — удаление; `.success` — готово.
- **Фокус:** двойное кольцо 2 px (bg + text-primary).

## Унификация

- **Одна кнопка.** `Button` — четыре формы одним компонентом: текст; иконка + текст; текст + иконка (`iconPosition="trailing"`); только иконка (без children, обязателен `label`, круг). Варианты: primary, secondary, tinted, surface, destructive, destructive-filled, plain. Размеры s / m (44), l (52), xl (64). Состояния: selected, loading, disabled. `IconButton` — сокращение для кнопки-иконки.
- **Одна шапка карточки.** `CardHeader`: иконка или аватар · надзаголовок · заголовок · подпись · хвост. Строки списка — только `ListRow` (тумблер, значение, шеврон — в `trailing`).
- **Одна поверхность.** Все карточки — `Card` (fill-1, `--radius-card`, `--pad-card`, `elev-1`); тона subtle / warning / error / inverse. Свой div с заливкой и радиусом не пишется.
- **Радиусы, поля, высоты — только токены:** `--radius-sheet | card | row | inner | pill`, `--pad-card | row | row-y | inner`, `--size-hit | button | button-xl | row`, `--gap-cards`, `--space-*`. Числа допустимы только для полос толщиной 1–4 px.
- **Отметки** — `SelectCircle`, **выбор из вариантов** — `ChoiceChips`, **ряды кнопок** — `ActionRow`, **шапки** — `FitHeader`, **подписи секций** — `SectionHeader`. Компонент Togo собирается из них, а не рисует свои.
- **Hex в компонентах нет.** Системные поверхности iOS (Live Activity, Dynamic Island) — токены `--system-*` в `tokens/togo.css`.

## Адаптивность

**Автопроверка:** `tests/fit-320.html` (размер L) и `tests/fit-320-ax1.html` (AX1) рендерят все компоненты в рамке 320 pt с полями 16 (контент 288) и пишут в консоль, что вылезает за край, обрезается, не помещается в кнопку или переносит заголовок шапки, который должен быть в одну строку. Добавили компонент — добавьте его в список `cases`.

Правила живут в компонентах, экраны их не дублируют и не подкручивают. Проверка — в крайнем сочетании **320 pt + AX1**.

- **Ряды кнопок** — только `ActionRow`. Кнопка не сжимается: если подпись не влезает, кнопка целиком уходит на новую строку.
- **Сетки** — `auto-fit, minmax(max(Npx, calc(var(--fs-body) * k)), 1fr)`. Колонок становится меньше вместе с ростом текста.
- **Строки «иконка · текст · хвост»** (ListRow, DiaryEntry, ReminderSchedule, LiveActivity, EscalationLadder, PermissionCard, InviteCard) — `flex-wrap`; текст `flex: 1 1 0; min-width: min(100%, calc(var(--fs-body) * 6))`; хвост `margin-left: auto`. Если места меньше одного слова, бейдж или время уходят на свою строку справа.
- **Шапки «Отмена · Заголовок · Готово»** — `FitHeader`. Если заголовок не помещается, он встаёт отдельной строкой над кнопками.
- **Колонки времени** (Timeline) — ширина от размера шрифта, одинаковая во всех строках.
- **Текст** не обрезается и не рвётся посреди слова: `overflow-wrap: break-word`, высоты через `min-height`.
- Подпись активного таба скрывается на 320 pt и при AX-размерах.

## «Сегодня» T5+ (утверждено)

Сверху вниз: шапка (иконки без подложек) → строка состояния (≤ 1, не прокручивается) → `ReadingCard` (показание · полоса до следующего · «дальше») → лента `FeedRow`, новое сверху, нижний край затухает → главная кнопка 64 + две по 52 → таб-бар. При прокрутке карточка сжимается в строку «время · дальше» (p = scrollTop / 150); карточка — вне скролл-контейнера. AX3 — карточка сразу свёрнута, кнопки столбиком.

## Правка и удаление

Запись — свайп (`SwipeRow`) или тап → шторка правки; удаление сразу, тост «Отменить» 5 с. Препарат, участник семьи, собака — `ConfirmDialog` (у препарата мягкий выход «Только остановить курс»; собака — ввести кличку). «Купил» отменяется тостом. Настройки и режимы — обратимы переключателями.

## Логика Togo

- **Медицина — режим, а не раздел.** «Здоровье» и «Лечение» появляются, только когда лечение включено (онбординг, шаг 3, или профиль).
- **Вердикт «просится»** — пять исходов: срочно, похоже на нужду, непонятно, скорее внимания, эпизод. Данных меньше чем за 4 дня — всегда «непонятно» с объяснением. «Вывожу» — первая акцентная кнопка в любом исходе.
- **Прогулка — режим.** «Вывожу» превращает вердикт в `WalkBar`; записи создаются в конце. Закончить без отметок — `Alert` с подтверждением.
- **Два тапа.** `QuickLog` → шит с одним вопросом (`ChoiceChips`) → «Записать». «Записано» — только после сохранения, в тосте с «Отменить».
- **Прерывают только три вещи:** доза по часам (`DoseCard`, `PushNotification`), окно натощак (`FastingWindow`), лестница эскалации (`EscalationLadder`). Всё остальное в тихие часы ждёт `MorningBrief`.
- **Режимы включаются событием или датой, не флагом.** Третий жидкий стул или кровь → `EpisodeCard` до явного «закончился». Поездка за 7 дней до даты → `TripCard`.
- **Ничего не теряется молча.** Удаление обратимо 5 с и оставляет зачёркнутый след. Две записи об одном в пределах 20 минут → `MergeCard`.
- **История** — `WeekStrip` + `Timeline` за день (промежутки подписаны, «сейчас» акцентом) или `WeekChart` за неделю. Тап по записи — шит с `TimeField` и удалением. Календарь — `Calendar` в шите; будущее неактивно.
- **Разрешения** — `PermissionCard` до системного запроса и только в момент нужды (уведомления — при первой дозе). После отказа — в Настройки, повторно не спрашивать.
- **Семья.** Приглашение — ссылка; приём — `InviteCard`. Третий человек — Pro.
- **Pro** открывает ровно три вещи: матрица переноса навыка, вторая собака, семья больше двух. Бесплатно навсегда: окно натощак, защита от двойной дозы, «Как попросил», «Не брал еду», отчёты врачу и CSV (`ExportCard`). Пробный период показывается, только если StoreKit подтвердил право на него.
- **Вне приложения:** `WidgetPreview` (small — сколько прошло, medium — плюс вердикт и «Вывожу»), `LiveActivity` (прогулка, окно натощак, занятие; экран блокировки и Dynamic Island).

## Текст

- **Длина на других языках.** Английский короче русского на 10–20 %, немецкий и французский длиннее на 20–35 %. Компоненты переносят строки сами, но: подписи кнопок — до 2 слов; чипы — до 14 символов; заголовок карточки — до 2 строк на 320 pt + AX1. Проверяйте экран на самом длинном языке.

- Русский, на «ты», без восторга. Эмодзи и восклицательных знаков нет.
- Словарь: выход, занятие, маркер, эпизод, доза, окно натощак, дежурный. Не использовать: событие, лог, данные, ошибка.
- Кнопки — глагол: «Записать», «Вывожу», «Дал», «Удалить», «Повторить». В навбаре «Изменить» / «Готово», в шите «Отмена» / «Готово».
- Регистр как в предложении.
- Статус пишется словом, не только цветом.
- Нет значения — «—» с причиной, никогда «0».
- Пустое состояние: что здесь будет → почему пусто → одно действие.
- Тосты: «Запись удалена», «Время изменено». Названия в «ёлочках».
- Алерт — только когда нужен ответ сейчас. Обратимое действие — тост с «Отменить», не алерт.

## Собачьи мотивы

Чтобы Togo не выглядел как любое приложение-трекер — четыре мотива из тех же токенов и иконок, без иллюстраций. Не больше одного на экран (лапа на маркере не считается).

- **Косточка** — полоса «до следующего» с двумя утолщениями на каждом конце (`ReadingCard`, вердикт). Не для запаса и не для загрузки.
- **Следы** — 4–5 глифов `pets`, повёрнутых на 90° и разнесённых ±6 px; бледнеют к началу, последний — `accent-text`. Пустые состояния («Здесь будут следы дня»), «Как это работает», пейвол.
- **Жетон** — форма адресника с кольцом: аватар собаки, бирка у двери (NFC). Аватары людей остаются кругом.
- **Лапа-действие** — `pets` только у действий собаки: «Просится», маркер «Да!» в занятии (круг 176 с ореолом `glass-tint-accent`), Pro. Не маркер списка и не декор.

Карточка — `guidelines/brand-motifs.html`, примеры — раздел «Собачьи мотивы» в `Togo ФИНАЛ.dc.html`.

## Иконки

- В коде — **SF Symbols**, вес равен весу соседнего текста.
- В макетах — **Material Symbols Rounded 300** (`tokens/icons.css`) как замена; соответствия на карточке «Иконки».
- Контурные по умолчанию; заливка — только у выбранного (активный таб, отмеченный пункт, «Разрешено»).
- Размеры: 24 рядом с body, 20–22 в мелких кнопках, 18 в пилюлях.
- У иконки без подписи обязателен `accessibilityLabel`.
- Своих SVG-иконок и иллюстраций нет. Логотипа нет — название набирается SF Pro Rounded 300.
