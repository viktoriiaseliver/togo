# Graphite — ядро дизайн-системы для iOS-приложений

Общая основа для всех приложений: графитовые поверхности, один акцент, крупные тонкие цифры, SF Pro и Dynamic Type. Здесь только то, что одинаково в любом продукте. Всё предметное (словарь, статусы, шкалы, мотивы, сценарии) живёт в продуктовом слое. Пример продукта — Togo (`readme.md`, `tokens/togo.css`, `components/togo*/`).

Визуальный каталог — `Graphite - дизайн-система.dc.html`.

## Три слоя

| Слой | Файлы | Кто меняет |
|---|---|---|
| Ядро | `graphite.css`, `tokens/` (кроме `<app>.css`), `components/atoms · molecules · organisms · feedback · inputs · media · states · pickers · data`, `guidelines/`, `ui_kits/templates/`, `tests/` | никто между приложениями; правка — для всех сразу |
| Бренд | `starter/brand.css` или `data-accent="orange|sky|pink"` | один акцент на тему |
| Продукт | `tokens/<app>.css`, `components/<app>-*/`, readme продукта | само приложение |

Слой ссылается только на предыдущий. Продукт не переопределяет токены ядра.

## Новое приложение

1. Скопировать `graphite.css`, `tokens/` (без чужих `<app>.css`), папки компонентов ядра, `guidelines/`, `starter/`, `ui_kits/templates/`, `tests/`, `GRAPHITE.md`. В Figma — `tokens/figma-variables.json` (коллекции Accent, Theme, Spacing, Layout, Radius, Size, Type, Motion) или `tokens.dtcg.json` через Tokens Studio.
2. Акцент — в `starter/brand.css` (правила ниже). Проверить контраст: тёмная, светлая, оба режима повышенного контраста.
3. Первые экраны — `ui_kits/templates/`: новый объект в `presets.js` (`tabs`, `noun`, `home`, `list`, `detail`, `settings`). Экраны не трогать. `starter/screen.html` и `starter/settings-profile.html` — заготовки.
4. Продуктовый слой: `tokens/<app>.css` подключается после `graphite.css`; компоненты — в `components/<app>-*/`, у каждого `.jsx`, `.d.ts`, `.prompt.md` и карточка `*.card.html`.
5. Проверка: `tests/fit-320.html` и `tests/fit-320-ax1.html` (новые компоненты добавить в `cases`), обе темы. После изменения цвета — аудит контраста по образцу `AUDIT.md`.

## Что разрешено продукту

- **Статусы — ссылками.** `--status-done: var(--accent-subtle)`, `--status-overdue: var(--status-error)`. Новый hex — только для своей шкалы (как запас у Togo), в обеих темах, с проверкой 4.5:1.
- **Компоненты — из ядра.** Предметный компонент собирается из Card, CardHeader, ListRow, ActionRow, Button, ChoiceChips, SelectCircle, SectionHeader, FitHeader. Своих поверхностей, радиусов и отступов нет.
- **Один фирменный мотив на экран.** Из токенов и иконок, без иллюстраций и своих SVG.
- **Свой словарь и голос.** Термины — в readme продукта. Правила текста ядра действуют всегда.
- **Нельзя:** второй акцент, свой шрифт, свои тени, hex в компонентах, warning/error как декор.

## Цвет

- **Тёмная тема** — графит: page #050503, bg #181818, fill #2C2C2C → #383838 → #454545. Вторичный текст #B2B2AE. Теней нет, глубина — ступенью светлее.
- **Светлая** — тёплые нейтральные: bg #F6F6F3, карточки белые, fill-2 #EFEFEB, fill-3 #E2E2DD, грань `fill-edge` #D9D9D3. Вторичный текст #5E5E59. Тени `elev-1` (карточки, строки) и `elev-2` (плавающее), без синевы.
- **Повышенный контраст** — `data-contrast="high"`: `accent-text` до 7:1, обводка у карточек, стекло непрозрачное.
- **Статусы ядра:** `status-error`, `status-warning` и их `-subtle`. Только в статусах и плашках. Статус пишется словом, не только цветом.
- **Системные поверхности iOS** (Live Activity, Dynamic Island) — `--system-*` в `tokens/system.css`, от темы не зависят.

### Акцент

Один цвет на тему, остальное выводится из него:

| Токен | Назначение |
|---|---|
| `accent` | заливка главной кнопки, «включено», выбранное |
| `accent-pressed` | нажатие, на ступень темнее |
| `on-accent` | текст на заливке: #0B0B0C, если заливка светлая; иначе #FFFFFF |
| `accent-text` | акцентный текст и ссылки, 4.5:1 к фону (HC — 7:1) |
| `accent-subtle` / `accent-subtle-text` | пастельный бейдж и его текст |
| `accent-knob` | ручка тумблера на акценте, 3:1 к заливке |
| `accent-edge` | грань главной кнопки (выводится через color-mix) |

Готовые акценты (светлая · заливка / текст): лайм #C6EF4E / #3A6A00 (по умолчанию), оранжевый #FF8A3D / #B04600, небо #4FA9FF / #0A5EAE, розовый #FF6FA3 / #B0285E. В светлой теме заливка — насыщенный средний тон, не пастель.

Акцент — главное действие и «включено». На экране одна залитая акцентом кнопка. Время и даты всегда нейтральные.

## Типографика

SF Pro, только системные стили Dynamic Type (`.font(.body)`, не `.system(size:)`). Заголовки 400, Headline 600. Цифры — SF Pro Rounded 300, табличные (44 / 56 / 80), растут не больше чем на 150 %. Минимум 12 px. Основной текст 17, вторичный 13–15.

## Форма и отступы

- **Радиусы:** шит 36, карточка 28, строка 24, вложенные 16. Ниже 64 pt — пилюля или круг (тост, поле, чип, плейсхолдер). Вложенный = внешний − padding: в строке 24 с полем 12 — 12, в шите 36 с полем 20 — 16. Только токены `--radius-*` или `calc()` из них, чисел нет.
- **Отступы — шаг 4.** Между карточками 8, между секциями 32, поле карточки 20, строки 16 × 12. Поля экрана 16 (320–374 pt) и 20 (от 375). Исключение — линии 1–4 px.
- **Касание** от 44 pt, основные кнопки 52, главная 64.
- **Стекло** — только плавающее: таб-бар, тост, меню, пуш. Блюр 20; при Reduce Transparency — непрозрачная заливка.
- **Грань кнопок:** тень снизу 3–4 px цветом грани варианта; при нажатии грань уходит, кнопка опускается.
- **Нажатие:** 0.96 (круглые 0.94), 0.15 s. Hover не оформляется.
- **Движение:** ease-out cubic-bezier(.2,.8,.2,1), 0.3 s. Reduce Motion — только прозрачность.
- **Хаптика:** `.selection` — тумблер и сегмент; `.impact(.light)` — порог свайпа; `.warning` — удаление; `.success` — готово.
- **Фокус:** двойное кольцо 2 px.

## Компоненты

- **Одна кнопка** — `Button`: текст; иконка + текст; только иконка (круг, обязателен `label`). Варианты primary, secondary, tinted, surface, destructive, destructive-filled, plain. Размеры s / m (44), l (52), xl (64).
- **Одна поверхность** — `Card` (тона subtle / warning / error / inverse). Свой div с заливкой и радиусом не пишется.
- **Одна шапка карточки** — `CardHeader`. Строки — только `ListRow`.
- Отметки — `SelectCircle`, выбор из вариантов — `ChoiceChips`, ряды кнопок — `ActionRow`, шапки шитов — `FitHeader`, подписи секций — `SectionHeader`.
- Только токены: `--radius-*`, `--pad-*`, `--size-*`, `--gap-cards`, `--space-*`.

## Адаптивность

Правила живут в компонентах; экраны их не подкручивают. Крайний случай — **320 pt + AX1**.

- Ряды кнопок — `ActionRow`: кнопка не сжимается, а уходит на новую строку.
- Сетки — `auto-fit, minmax(max(Npx, calc(var(--fs-body) * k)), 1fr)`.
- Строки «иконка · текст · хвост» — `flex-wrap`, хвост уходит на свою строку.
- «Отмена · Заголовок · Готово» — `FitHeader`: длинный заголовок встаёт над кнопками.
- Текст не обрезается: `overflow-wrap: break-word`, высоты через `min-height`.
- Подпись активного таба скрывается на 320 pt и при AX-размерах.

## Текст (для любого продукта)

- Регистр как в предложении. Без эмодзи и восклицательных знаков.
- Кнопки — глагол, до 2 слов. В навбаре «Изменить» / «Готово», в шите «Отмена» / «Готово».
- Нет значения — «—» с причиной, не «0».
- Пустое состояние: что здесь будет → почему пусто → одно действие.
- Обратимое действие — тост с «Отменить» (5 с). Алерт — только когда нужен ответ сейчас. Необратимое (удаление сущности) — `ConfirmDialog`.
- Длина на других языках: немецкий и французский длиннее русского на 20–35 %. Чипы — до 14 символов, заголовок карточки — до 2 строк на 320 pt + AX1.

## Иконки

- Код — SF Symbols, вес как у соседнего текста. Макеты — Material Symbols Rounded 300.
- Контурные по умолчанию; заливка — только у выбранного.
- 24 рядом с body, 20–22 в мелких кнопках, 18 в пилюлях. У иконки без подписи — `accessibilityLabel`.
- Логотипа нет: название приложения набирается SF Pro Rounded 300.
