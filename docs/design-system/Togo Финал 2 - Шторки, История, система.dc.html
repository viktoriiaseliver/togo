История v4 · тихо и понятно

Шкала с дорожками убрана с первого экрана: для вопроса «как прошёл день» она шумная. Остались ответ словами, исключение отдельной строкой и четыре итога с сравнением с обычным — как сводка в Apple Health. Шкала по часам — по кнопке «День по часам». Цвет только у исключения.
