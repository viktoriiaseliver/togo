Graphite

Общая основа для iOS-приложений: графитовые поверхности, один акцент, крупные тонкие цифры, SF Pro и Dynamic Type. Новое приложение получает своё лицо через акцент и продуктовый слой. Ядро при этом не меняется.

Как пользоваться

Три слоя

Каждый следующий слой ссылается только на предыдущий. Продукт не переопределяет токены ядра и не пишет hex в компонентах.

1 · не меняется Ядро Поверхности, текст, статусы, шрифт, отступы, радиусы, движение. Атомы, молекулы, организмы, ввод, дата и время, данные, обратная связь. graphite.css
tokens/
components/atoms … states/
2 · один файл Бренд Один акцент на тему: заливка, текст, пастельный бейдж, ручка тумблера. Готовые — лайм, оранжевый, небо, розовый. Шрифт, форма и отступы общие. starter/brand.css
или data-accent="orange|sky|pink"
3 · своё у каждого приложения Продукт Смысловые статусы как ссылки на статусы ядра, свои шкалы, предметные компоненты, словарь и голос, один фирменный мотив. tokens/<app>.css

Новое приложение за пять шагов
  1. 1Скопировать graphite.css, tokens/, папки компонентов ядра и starter/. В Figma импортировать tokens/figma-variables.json.
  2. 2Задать акцент в starter/brand.css и проверить контраст в обеих темах и в повышенном контрасте.
  3. 3Собрать первые экраны из ui_kits/templates/: новый объект в presets.js, экраны не трогать.
  4. 4Добавить продуктовый слой: tokens/<app>.css и components/<app>-*/ с .jsx, .d.ts, .prompt.md и карточкой.
  5. 5Прогнать tests/fit-320.html и fit-320-ax1.html, светлую и тёмную тему.
Что разрешено продукту
  • Статусы — ссылками--status-done: var(--accent-subtle). Новый hex — только для своей шкалы, с проверкой 4.5:1.
  • Компоненты — из ядраCard, CardHeader, ListRow, ActionRow, Button, ChoiceChips, SelectCircle. Своих поверхностей и радиусов нет.
  • Один мотив на экранИз токенов и иконок, без иллюстраций. Описывается в readme продукта.
  • Свой словарьТермины и голос — в продукте. Правила текста ядра действуют всегда.
