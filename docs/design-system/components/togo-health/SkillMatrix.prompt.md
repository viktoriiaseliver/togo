Матрица переноса навыка — функция Pro. Строки — навыки, столбцы — места. Уровень растёт из занятий (TrainingTimer): 0 не начато, 1 учим (кольцо), 2 держит (пастель с точкой), 3 надёжно (заливка с галочкой). Статус читается формой, не только цветом.
```jsx
<SkillMatrix contexts={["Дом","Двор","Парк","Город"]} skills={[{name:"Место",levels:[3,2,1,0]}]} />
```
