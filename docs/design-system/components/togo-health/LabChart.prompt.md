График анализа (Т4, ТТГ): коридор нормы пастелью, линия значений, точки вне нормы — красные и крупнее, пунктир — смена дозы. Последнее значение — в шапке словом «в норме / вне нормы». Подписи дат на узком экране — только первая и последняя.
```jsx
<LabChart points={[{date:"12 мар",value:18},{date:"2 мая",value:31}]} range={{low:19,high:58}} doses={[{at:0,label:"200 мкг"}]} />
```
