Шапка карточки — одна на всю систему. Внутри `Card` первым элементом.
```jsx
<Card><CardHeader icon="luggage" tone="accent" kicker="Поездка · 12–19 окт" title="Лион" trailing={<span>через 5 дн.</span>} /></Card>
<Card><CardHeader icon="notifications" tone="accent" title="Уведомления" subtitle="Чтобы доза не прошла мимо" /></Card>
```
