Карточка дозы — одна из трёх вещей, которым разрешено прерывать. Защита от двойной дозы — в note и состоянии taken.
```jsx
<DoseCard state="due" name="Левотироксин" dose="200 мкг · 1 таблетка" time="07:00" onGive={give} />
<DoseCard state="waiting" name="Завтрак" dose="После дозы" time="07:40" note="Кормить можно через 25 мин" />
```
