Live Activity на экране блокировки и в Dynamic Island: прогулка переживает закрытие приложения, окно натощак показывает обратный отсчёт. Цвета фиксированные (тёмная подложка системы).
```jsx
<LiveActivity title="Прогулка" elapsed="12:40" detail="Пописал · 1" />
<LiveActivity island kind="fast" elapsed="25 мин" />
```
