Настройки напоминаний по часам: список с тумблерами, тихие часы (всё, кроме дозы, ждёт утреннего брифа), право дозы пробивать тишину. Тап по строке открывает TimeField в шите.
```jsx
<ReminderSchedule items={[{title:"Доза",time:"07:00",repeat:"каждый день",on:true}]} quiet={{on:true,from:"23:00",to:"07:00"}} critical />
```
