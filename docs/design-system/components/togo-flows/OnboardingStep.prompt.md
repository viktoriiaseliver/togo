Шаг онбординга: прогресс, один вопрос, одно главное действие. Ставится прямо на фон экрана (`bg-primary`), без карточки: поля и чипы внутри — fill-1 и должны быть на ступень светлее фона. Не больше трёх шагов: имя собаки → режим дня → лечение (можно пропустить).
```jsx
<OnboardingStep step={1} total={3} title="Как зовут собаку?" primary="Дальше"><TextField value={n} onChange={setN} /></OnboardingStep>
```
