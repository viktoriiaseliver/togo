Предварительный экран разрешения. Показывается до системного запроса и только в момент, когда разрешение нужно (уведомления — при первой дозе). После отказа ведёт в Настройки, не спрашивает снова.
```jsx
<PermissionCard title="Уведомления" reason="Чтобы доза по часам и окно натощак не прошли мимо" onAllow={ask} onLater={later} />
```
