## 2. Цвета вместе — не сливаются

- **Иерархия поверхностей, тёмная:** bg #181818 → fill-1 #2C2C2C → fill-2 #383838 → fill-3 #454545. Каждая ступень светлее на 1.19–1.27:1 (было 1.12 между fill-1 и fill-2 — вложенное сливалось).
- **Светлая:** bg #F0F0F3 → карточка #FFFFFF (с тенью elev-1) → вложенное #E6E6EB → нажатое #D6D6DC. Карточка отделяется тенью, вложенное — темнее карточки.
- **Пастельные плашки** (accent-subtle, warning-subtle, error-subtle) усилены по насыщенности, чтобы отличаться друг от друга и от карточки: тёмная error-subtle #4D1F22 (было коричневое #4A2A22), warning-subtle #4A300A; светлая #FDE3E1, #FFEFCF, лайм #E6F4C8.
- **Пастель всё равно близка по светлоте** — это свойство пастели. Правило: плашка статуса всегда несёт иконку и слово цветного текста, цвет не единственный признак.
- **Оранжевый акцент близок к предупреждению и ошибке** (ΔE 0.09). Для приложений со статусами здоровья (Togo) оранжевый акцент не используется; по умолчанию лайм. Для других проектов допустим.

## 3. Названия

125 переменных, 9 коллекций. Дублей нет, все имена в нижнем регистре через «/» и «-». Схема: `группа/роль/вариант` — `color/fill/1`, `color/text/secondary`, `color/status/error-subtle`, `space/16`, `layout/pad-card`, `radius/card`, `type/size/body`. CSS-имя = последняя часть пути (`--fill-1`, `--space-16`).

## 4. Унификация

- Кнопки — один `Button` (7 вариантов × 4 размера × 4 формы × 3 состояния).
- Поверхности — `Card`, шапки карточек — `CardHeader`, строки — `ListRow`, ряды кнопок — `ActionRow`, выбор — `ChoiceChips` / `SelectCircle` / `Menu`.
- **Hex в компонентах — 0.** Последние 4 случая (ручка слайдера, иконка на скриме, отметки прогулки, плашка экстренной карточки) вынесены в токены `--control-knob`, `--on-scrim`, `--fill-on-inverse`, `--fill-on-color`.
- **Размер шрифта числом — 0** (крупные цифры виджета — `--fs-number-s`).
- **Отступы — только шаг 4**, проверено по всем файлам компонентов, карточек, шаблонов.

## 5. Состояния

- У всех нажимаемых элементов общий фокус (двойное кольцо 2 px) и курсор неактивного — в `base.css`, а не в каждом компоненте.
- Нажатие (масштаб + ступень заливки) у `Button`; у плиток и строк — ступень заливки.
- Загрузка, пусто, ошибка, нет сети: `Button loading`, `ListSkeleton`, `EmptyState`, `InlineAlert error`, `SyncStatus offline`.
- Удаление обратимо 5 с (`Toast undo`) и оставляет след (`DiaryEntry deleted`, `Timeline deleted`).

## 7. Перенос в Figma

1. Tokens Studio → Import → `tokens/tokens.dtcg.json` → Export to Figma Variables. Или любой импортёр Variables из JSON — `tokens/figma-variables.json` (коллекции, режимы, алиасы в явном виде).
2. Порядок коллекций: Accent → Theme → Togo → Spacing → Layout → Radius → Size → Type → Motion (алиасы ссылаются только назад).
3. Scopes: `color/text/*` — Text fill; `color/bg/*`, `color/fill/*` — Frame fill, Shape fill; `color/line/*` — Stroke; `space/*`, `layout/*` — Gap, Padding; `radius/*` — Corner radius; `size/*` — Width/Height.
4. Тени (`effect/elevation/*`) и стекло — Effect Styles, не переменные: Figma не хранит тени в Variables.
