# Togo — задание на финальный чистовик

Цель: один файл `Togo ФИНАЛ.dc.html` со ВСЕМИ экранами в стиле «Сегодня v3», готовый к переносу в Figma.

## Эталон стиля
`Togo Финал 1 - Сегодня v3.dc.html`:
- показание: SF Pro Rounded 300, единица мелко сверху акцентом;
- таймлайн: время в нейтральной капсуле, иконка + подпись, кто отметил — словом, количество — акцентом, ≤2 тегов;
- «дальше» — последняя строка таймлайна с пустым акцентным кружком, не отдельная карточка;
- одна главная кнопка 64 с гранью, две второстепенные 52, у каждой кнопки иконка;
- только токены `styles.css`, тема через `data-theme`;
- тексты: строка ≤7 слов, одна мысль, сначала главное, без воды; минимум 13 pt; касание ≥44.

## Состав
1. Сегодня — 10 состояний, Dark; Light 01/03/05; SE 375; AX3 (есть в v3).
2. Шторки: Просится (вердикт-шкала), Записать…, Инцидент + Другое…, Вырвал · Другое… (есть в Финале 2 — переписать тексты).
3. На улице: режим поведения, итог со срывом, «Как сходил?» — ПЕРЕРИСОВАТЬ в v3.
4. История v4 + «День по часам» (нарисовать).
5. Запас: список, карточка препарата (мл, ½, курс, вскрытие).
6. Онбординг 3 шага — ПЕРЕРИСОВАТЬ.
7. Уведомления, экран блокировки, Dynamic Island (compact/minimal/expanded), виджеты (small, medium, lock, Watch), StandBy — ПЕРЕРИСОВАТЬ.
8. Разворот 874×402, iPad 1194×834.
9. Профиль → Режимы (лечение, поведение, туалет), Настройки уведомлений, Семья/приглашение — нарисовать.
