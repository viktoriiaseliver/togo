# Togo — утверждённые решения

- Главный экран «Сегодня»: утверждён концепт из `Togo Главный экран - разбор.dc.html` — один каркас, содержание меняется по состоянию дня. Каркас: аватар · показание (время с выхода) · «сегодня» (2 последние записи) · ≤1 строка состояния · 1 главная кнопка 64 pt · 2 второстепенные · таб-бар. Кнопки с гранью снизу.
- Остальные записи — в шторке «Записать…» (инцидент первым).
- Проверка концепта (покрытие, масштаб, тесты): `Togo Главный экран - проверка.dc.html`.
- Запас лекарств и корма: списывается с отметок, строка состояния за 7 дней, «Купил» пополняет у всей семьи.
- Таблетка на прогулку: если до/после дозы ≤ 30 мин — строка в шторке «Просится» и в режиме «На улице» («Дал», если препарат можно дать на улице).
- Чистовик: `Togo Чистовик - начни здесь.dc.html` → `Togo Финал 1 - Сегодня v3.dc.html` (таймлайн + «дальше»; v2 «Финал 1 - Сегодня» — предыдущая версия) и `Togo Финал 2 - Шторки, История, система.dc.html`. Файлы «архив - …» — история, не использовать.
- «Сегодня» — утверждён T5+ из `Togo Сегодня - таймлайн.dc.html` (заменяет таймлайн v3): карточка B (показание + полоса до следующего + «дальше») над прокручиваемой лентой «новое сверху» с затуханием у нижнего края; при прокрутке карточка сжимается в строку «время · дальше», кнопки и таб-бар неподвижны. Иконки шапки без подложек, строка тревоги не уезжает. ФИНАЛ собирать в этом стиле.
- Цвета и шрифт — только из дизайн-системы Togo (Lime-акцент, янтарь только натощак, терракот — инцидент/тревога и запас ≤ 3 дней, оранжевый `--stock-low` — запас ≤ 7 дней).
- Светлая тема v3 (окт 2026): тёплый нейтральный вместо холодного серого, лайм #C6EF4E, грань `--fill-edge` своя. Значения — `tokens/colors.css`.
- Единый чистовик — `Togo ФИНАЛ.dc.html` (все экраны). Описание для Claude Design — `ФИНАЛ - для Claude Design.md`.
- Ядро Graphite для новых приложений: `GRAPHITE.md`, `graphite.css`, `Graphite - дизайн-система.dc.html`. Togo — продуктовый слой (`styles.css` = ядро + `tokens/togo.css`); предметное в ядро не добавлять.
- Правка и удаление: запись — свайп или шторка, удаление с тостом 5 с; препарат, участник, собака — с подтверждением.
- Собачьи мотивы (окт 2026): косточка (полоса до следующего), следы (пустые состояния, «Как это работает», пейвол), жетон (аватар собаки, бирка у двери), лапа — только у действий собаки. Не больше одного мотива на экран.
- «Сегодня»: состояния с концом — прогулка (слайдер «Домой»), поездка («Закончить»), выездной день («Вернулись»).
