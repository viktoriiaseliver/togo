Мобильная дизайн-система · iOS 17+ · v0.2

Graphite

Атомная система: токены → атомы → молекулы → организмы → шаблоны. Компоненты ссылаются только на семантические токены, поэтому акцент, тема, размер текста и повышенный контраст меняются в одном месте. Переключатели — в панели Tweaks. Цвета пересчитываются под контраст автоматически.

Акцент = состояние. Заливка — только «включено» и одно главное действие на экране. Ошибка и предупреждение — только в статусах.

05

Паттерны

Свайп Влево: Удалить (справа, заливка error) + Изменить. Частичный свайп > 60 pt — открывает 144 pt действий. Полный свайп > 60 % ширины — удаляет сразу, хаптика на пороге, затем тост «Отменить». Вправо: одно недеструктивное действие (закрепить, отметить). Дублирование. Любое действие свайпа есть ещё в контекстном меню (долгое нажатие) и в режиме правки — свайп не обнаруживается сам. SwiftUI: .swipeActions(edge: .trailing, allowsFullSwipe: true).
Редактирование Один объект: тап по строке → шит с формой. «Готово» неактивна, пока нет изменений или есть ошибка. Много объектов: «Изменить» → выбор кружками, перетаскивание за ручку, таб-бар заменяется панелью действий. Выход: «Готово» сохраняет. Отмена с несохранёнными правками спрашивает подтверждение. Ошибка — под полем, текстом и цветом, фокус остаётся в поле.
Удаление Обратимое, один объект: без вопроса, сразу тост с отменой. Массовое или с вложенными данными: диалог подтверждения, кнопка с числом («Удалить 3 комнаты»), «Отмена» — жирная. Необратимое (аккаунт, общий доступ): диалог + ввод названия или Face ID. Строка схлопывается 0.3 с, соседние поднимаются; при Reduce Motion — исчезает.
Отмена действий Тост 5 с после удаления, правки, массового действия. Объект возвращается на прежнее место. Встряхивание — системный Undo (UndoManager), работает и после скрытия тоста. Серверное удаление откладывается до исчезновения тоста — отмена не требует сети. Тост с отменой не закрывается VoiceOver-фокусом до конца таймера.
Пустые состояния Каждый список, карточка и экран описывает: загрузку, первый запуск, нет результатов, очищено, ошибку, нет доступа. Формула: иконка в круге → что здесь будет (body) → почему пусто (footnote) → одно действие. Значение без данных — «—» и причина. Никаких нулей вместо пустоты. SwiftUI: ContentUnavailableView со своими стилями.

Свайп влево по строке — действия; до конца — удалить. Тап — шит редактирования; пустое имя даёт ошибку. Изменить — выбор нескольких, удаление с подтверждением.
