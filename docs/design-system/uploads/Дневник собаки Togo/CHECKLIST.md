# Чек-лист: Togo — новая архитектура

Порядок важен: модель данных (этап 3) — до режима «На улице» (этап 4), чтобы не мигрировать дважды. Каждый пункт: что сделать · где · как проверить. Подробности поведения — в `README.md`.

Правила сессии из `CLAUDE.md` репозитория: `git log` → верх `СТАТУС.md` → последняя запись `docs/journal/` → работа → `make journal`, верх `СТАТУС.md`, коммит. Приёмка — по кадрам и живому телефону, не по «тесты зелёные».

## Этап 1 · Дефекты (независимы, можно сразу)

- [ ] **Инцидент на улице с видом.** `WalkMode.swift`: плитка «Инцидент» открывает шторку вида (вырвал · подобрал с земли · Другое…). Вынести `raiseEpisodeIfNeeded` из `IncidentSheet.swift` в общий тип (`TogoShared/Domain` или `Togo/Store`) и звать из обоих мест. При записи из прогулки — `incidentKind`, `toldFamily`, эпизод.
  - Тест: инцидент на прогулке → `incidentKind != nil`; второй за сутки → эпизод открыт.
- [ ] **Вход в «Сводку врачу» у здоровой собаки.** `DogTab.swift`, группа «когда спросят»: `TGLink("Отчёт врачу") { VetSummaryScreen(dog:) }`.
  - Тест: у собаки без лечения экран достижим (UI-тест).
- [ ] **«Уход и прививки».** Подпись в `DogTab.swift` и `HealthScreen.swift` (`Прививки и визиты` → `Уход и прививки`); значение строки — ближайшая прививка.
- [ ] **Вес — одна подпись.** `HealthScreen.swift`: «Вес и симптомы» → «Вес».
- [ ] **Siri и «Команды» через `EventLog`.** `Togo/Intents/*`: записи через `EventLog.record`, а не мимо.
  - Тест: запись из интента проходит проверку права и сторожа дубля.
- [ ] **«Сказать остальным».** До этапа 2 — скрыть переключатель в `IncidentSheet` (он ничего не отправляет); вернуть вместе с тихими уведомлениями.

## Этап 2 · Уведомления

- [ ] `ReminderScheduler.scheduleDoses`: добавить уведомление **в час дозы** (`.timeSensitive`, звук); «заранее» — `.passive` по `Settings.doseLeadMinutes` (по умолчанию 0 = выкл); +30 — по `Settings.doseOverdueReminder`; **+60 убрать**, пропуск — в `briefLines` и режиме дня.
- [ ] `NotificationCenterService`: зарегистрировать `UNNotificationCategory("dose")` с действиями `GIVEN` («Дал») и `SNOOZE15` («Через 15 минут»).
- [ ] `TogoApp.swift`: `UNUserNotificationCenterDelegate` — `willPresent` (баннер при открытом приложении), `didReceive`: `GIVEN` → доза через `EventLog`, `FeedingGate`, `cancelDose`; `SNOOZE15` → перепланировать; тап → строка дозы на «Сегодня».
- [ ] «Беру на себя»: заменить запланированные уведомления этой дозы текстом «<Имя> даёт, с HH:MM» без кнопок.
- [ ] `FamilySync`: при приёме чужой записи — локальное уведомление `.passive` по настройкам; рвота/кровь — `.active`; при чужой дозе — `ReminderScheduler.cancelDose` у себя.
- [ ] Вернуть «Сказать остальным» в инциденте — через этот механизм.
- [ ] `SettingsScreen` → новый экран **«Уведомления»** (состав — README §5).
- **Готово, когда** на двух телефонах: доза в 8:00 звенит у обоих; мама жмёт «Дал» в уведомлении → у тебя тихое «Мама дала дозу», +30 не приходит. Замерить задержку тихого уведомления и записать в журнал.

## Этап 4 · Режим «На улице»

- [ ] `ActiveSession`: один вид с `origin`; `startOuting`/`startWalk` → общий старт.
- [ ] `WalkMode.swift`: убрать `startSheet` («Пошли»); старт по тапу; 10 секунд «Отменить»; отметки: Пописал · Стул · Срыв (только `behaviorWork`) · Инцидент · Лакомство · Заметка; убрать «Занятие»; «Закончить» → «Домой».
- [ ] «Домой»: итог только при срыве/инциденте/заметке; `origin == .needs` без отметок → тост с «Как сходил?»; иначе тост «Уточнить».
- [ ] `WalkSummarySheet`: строки инцидента (чем, кровь → звонок) и срыва (расширенные поля в режиме поведения).
- [ ] `NeedsSheet.swift`: чипы «Как попросил» в шторке над кнопками; удалить `HowAskedSheet`; «Не сейчас» пишет `NeedAsk`.
- [ ] `WalkSheets.swift`: `WalkResultSheet` → тост; `OutingFinisher` — общий для обоих `origin`.
- [ ] `ActiveSessionCard`: «Открыть» для обоих; тап по карточке открывает.
- [ ] `TimelineBuilder`: блок «на улице · N мин», подпись по `origin`.
- [ ] `LiveActivityController`, `WalkActivityAttributes`, `WalkMarkIntent`: единый режим.
- [ ] Подсказка «просится погулять, а не в туалет» — после 5 `notToilet` за неделю.
- Тесты: просьба → «Домой» без отметок → `notToilet`; «Не сейчас» + лужа за 60 мин → `toilet`; инцидент из режима → эпизод; прогулка без вопросов → итог не показывается.
- **Готово, когда** F1 = 3 тапа, F2 = 2 тапа на живом телефоне (README, «Флоу»).
