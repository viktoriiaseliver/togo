# Handoff: Togo — новая информационная архитектура, флоу и режимы собаки

Репозиторий: `viktoriiaseliver/togo` (ветка `main`). Документ самодостаточный: разработчик, не видевший переписку, должен суметь реализовать всё отсюда. Пошаговый список работ с галочками — в `CHECKLIST.md`.

## Обзор

По итогам продуктового исследования (аудит кода, 13 утверждённых решений, карточная сортировка, тест дерева, международное исследование, подборка с форумов) меняются:

1. **Режим «На улице»** — один экран вместо «выхода» и «прогулки».
2. **Инцидент на улице** — с видом, через `EventLog`, с эпизодом и кровью.
3. **Уведомления** — звук в час дозы, «Дал» прямо в уведомлении, тихие уведомления о действиях семьи, отдельный экран настроек.
4. **Три режима собаки в профиле** — «Лечение» (есть), «Работа с поведением» (новый), «Туалет»: улица · пелёнка · переход (новый).
5. **«Другое…»** — у каждого неполного списка выбора последний чип раскрывает поле ввода; свой ответ, введённый дважды, становится чипом этой собаки.
6. **Структура** — онбординг в 3 шага, полоса тревоги со звонком врачу, вкладка «Собака» 3 + 3, курсы в Истории, вход в «Сводку врачу» и прививки у здоровой собаки.

## О файлах дизайна

Файлы `*.dc.html` в этой папке — **дизайн-референсы в HTML**, а не код для переноса. Задача — воспроизвести поведение и структуру в SwiftUI-коде Togo по его правилам: только `Token.*` и `TG*`-компоненты в `Togo/Features`, значения — только в `DesignTokens/tokens.json`, без сторонних зависимостей. Открываются в браузере (рядом лежит `support.js`).

## Точность

**Low-fidelity.** Вайрфреймы показывают состав, порядок блоков и поведение. Цвета, шрифты и отступы — из существующей темы Togo (тёмная, единственная; `Token.Action.primary` — главное действие, `Token.Status.waiting` — только окно натощак, `Token.Status.overdue` — пропуск дозы, кровь, удаление). Тексты в макетах — черновые; финальные проходят через `make texts` и словарь интерфейса.

## Правила, которые нельзя нарушить

- Не больше трёх шагов от вкладки до чего угодно: вкладка → экран → форма.
- Режимы переключаются только в профиле, никогда с главного экрана.
- «Вывожу» — первая кнопка во всех исходах вердикта.
- Прерывать человека (звук, time-sensitive) могут только: доза в её час, «не отмечена» через 30 минут, конец окна натощак, лестница эскалации, рвота/кровь у семьи.
- Ничего не теряется молча: каждая запись через `EventLog`, отмена 5 секунд, «Записано» только после успешного save.
- Бесплатно навсегда остаётся бесплатным; отчёт врачу и CSV — бесплатны.
- Журнал действий (`UsageLog`) не хранит текст пользователя — только имена действий.

## Экраны и поведение

### 1. «Сегодня» (вкладка)

Блоки сверху вниз; одновременно показывается **не больше одной подсказки** (п. 3), приоритет: тревога → «учусь ритму» → «привыкает к улице» → «кто ещё кормит».

1. Заголовок «Сегодня» · шестерёнка.
2. **Полоса тревоги** (`Token.Status.overdue`): кровь в стуле/рвоте; 3 эпизода за 6 ч (уже есть `AlarmThreshold`); тишина мочи ≥ 12 ч и просьба без результата (`UrineSilence`). Кнопки: «Позвонить» (номер врача из `EmergencyScreen`), «Что сказать врачу», «Подожду час» (→ `ReminderScheduler.remindToWatch`).
3. **Герой** «N ч назад» или таймер «на улице» с «Открыть».
4. Одна подсказка:
   - «Учусь ритму Стича» — дни 1–4, 4 сегмента прогресса, «2 дня из 4 · 9 выходов записано». Заменяет формулировку «Непонятно» в вердикте.
   - Режим туалета «переход»: «Привыкает к улице · за неделю: улица 7 · пелёнка 3». После 7 дней без пелёнки — одноразовое предложение переключить на «Улица».
   - «Кто ещё кормит?» — с 3-го дня, если в семье один человек; крестик закрывает навсегда.
5. Режим поведения: строка под героем «Сегодня 3 триггера — день потише» (считаются и срывы, и испуги).
6. Режим дня: дозы, еда, окно натощак, сроки ухода.
7. Лента дня: «на улице» — блоком с отметками внутри.
8. Сетка действий (закреплена снизу):
   - туалет «улица» и «переход»: `Просится` (главная) · `Гулять` / `Стул` · `Еда` · `Инцидент` · `Ещё`
   - туалет «пелёнка»: `Гулять` (главная, во всю ширину) / `Стул` · `Еда` · `Инцидент` · `Ещё`
   - «Ещё»: Лакомство · Занятие · Заметка · (переход) Пелёнка · Собака со мной весь день. Строку «Всё про собаку» убрать.

### 2. Шторка «Просится»

1. Вердикт (заголовок + одна фраза почему). 2. Факты. 3. **«Как попросил»** — строка чипов прямо в шторке над кнопками, только когда `Diary.shouldAskHowAsked` (смена сигнала или раз в 5); необязательно; последний чип «Другое…». Отдельная шторка `HowAskedSheet` удаляется. 4. `Вывожу` (главная) · `Не сейчас`.

**Кнопки «Поиграли» нет.** Вердикт учится по последствиям:
- «Вывожу» → на улице без отметок мочи/стула → «Домой» → просьба = «не в туалет».
- «Не сейчас» → 60 минут без лужи → «не в туалет».
- «Не сейчас» → лужа в течение 60 минут → «настоящая»; вердикт осторожнее.
- После 5 просьб «не в туалет» в течение часа после прогулки за неделю — одноразовая подсказка на «Сегодня»: «Просится погулять, а не в туалет. Вышли, дела, домой; играть — дома».

В режиме туалета «пелёнка» кнопки «Просится» и вердикта нет.

### 3. Режим «На улице» (полноэкранная шторка)

Старт из «Вывожу» (`origin = .needs`) или «Гулять» (`origin = .walk`). Таймер идёт сразу; первые 10 секунд в тосте «Отменить».

Состав сверху вниз: таймер · «на улице · с 12:36» · «Свернуть» → список «отмечено» с «Убрать последнюю» → `Пописал` (крупная, `Token.Action.primary`, высота ≥ 72) → `Стул` · `Срыв` (только режим поведения, `Status.waiting`-фон как сейчас) → `Инцидент` · `Лакомство` · `Заметка` → `Пауза` · `Домой` (Домой шире, 1:2).

Из отметок убрать «Занятие» (оно в «Ещё»).

**`Инцидент`** открывает шторку вида поверх режима (таймер идёт): `Вырвал` · `Подобрал с земли` · `Другое…` (поле). Запись — через тот же путь, что дома: `EventLog.record(.incident…)`, `incidentKind`, `toldFamily`, проверка эпизода. Сейчас отметка пишется без вида и мимо эпизода — это дефект.

**«Домой»** — записи создаются разом, время от старта. Затем:
- есть срыв, инцидент или заметка → **итог** (шторка): по строке на каждый факт; «с кровью» → полоса «Позвонить врачу»; ответы сохраняются и при свайпе;
- `origin == .needs` и нет отметок → тост со строкой чипов «Как сходил?» (пописал · стул · оба · не сходил); не ответил — запись без результата;
- иначе → тост «На улице 34 мин · пописал 2 · Уточнить».

Итог срыва: «На что» (чипы + Другое…) · «Как близко» (вплотную · ≈5 м · далеко). В режиме поведения ещё: «Как реагировал» (лаял и рвался · замер · пытался уйти · рычал · Другое…), «Мог взять лакомство» (да · нет), «Пришёл в себя за» (< 1 мин · 1–5 мин · дольше), «Что помогло» (отошли дальше · развернулись · лакомство · ничего · Другое…). Всё необязательно.

Свёрнутый режим: герой на «Сегодня» показывает таймер; одна карточка с «Открыть» для обоих `origin`; Live Activity с «Пописал».

### 4. Инцидент дома

Шторка вида: `Вырвал` · `Лужа в доме` (в режиме «пелёнка» — «Мимо пелёнки») · `Стул в доме` · `Сорвался` · (режим поведения) `Испугался` · `Другое…`. Тап — записано. Второй экран остаётся только там, где есть что сказать:
- вырвал → «чем» (едой · желчью · травой · с кровью · не разобрала · Другое…); кровь → полоса со звонком;
- лужа/стул в доме → «Не наказывай» + «что было до» (как сейчас);
- испугался → «от чего» (тревога · салют · гроза · гости · звонок в дверь · Другое…).
Остальное — тост с «Уточнить».

### 5. Уведомления

Схема для дозы (на каждую `DoseRecord`):

| Когда | Уровень | Текст | Условие |
|---|---|---|---|
| заранее (выкл/5/10/15 мин, по умолчанию выкл) | `.passive` | «Через 10 минут доза» | настройка |
| в час дозы | `.timeSensitive`, звук | «Доза 8:00 · Левотироксин» / «0,1 мг. Кормить можно с 8:30.» | всегда при лечении |
| +30 | `.timeSensitive`, звук | «Доза 8:00 не отмечена» | настройка, вкл |
| +60 | — | убрать пуш; пропуск — строкой в режиме дня и в утренней сводке | — |

- Категория `dose` регистрируется (`UNNotificationCategory`) с действиями `Дал` (пишет дозу через `EventLog`, запускает `FeedingGate`, снимает +30) и `Через 15 минут`. Нужен `UNUserNotificationCenterDelegate` в `TogoApp`: `willPresent` (баннер при открытом приложении) и `didReceive` (действия, тап ведёт к строке дозы).
- Если дозу «взяли на себя» — заменить запланированные уведомления текстом «Мама даёт, с 7:58» без кнопок.
- **Тихие уведомления о семье**: при приёме чужой записи в `FamilySync` — локальное уведомление `.passive` по настройкам; при чужой дозе — сразу снять свои +30 по этой дозе. Рвота и кровь — `.active` со звуком. Переключатель «Сказать остальным» в инциденте начинает работать через этот же механизм (сейчас он ничего не отправляет).
- Экран **Настройки → Уведомления**: «Доза» (в час дозы — всегда · заранее › · если не отметили за 30 мин) · «Когда отмечают другие · тихо» (дали дозу вкл · покормили выкл · вывели выкл · инцидент вкл, «рвота и кровь — со звуком») · «Прочее» (можно кормить · утренняя сводка ›).

### 6. Профиль → Режимы

Секция «Режимы»: `Лечение` (тумблер, как сейчас) · `Работа с поведением` (тумблер; подпись «срывы и страхи: триггеры, дистанция, восстановление») · `Туалет` (› экран выбора: Улица · Пелёнка · Переходим на улицу; пояснение «Пелёнка и улица вместе путают собаку…»).
- Онбординг, шаг 2 «Режим»: еда · лечение · туалет (одним тапом).
- «Работа с поведением» в онбординге не спрашивается; после 3-го «Сорвался» за неделю — одно мягкое предложение включить.
- Пелёнка: переключатель «Отмечать пелёнку» (по умолчанию выкл) — для случаев, когда врач просит считать мочеиспускания.

Режим поведения включает: плитку «Срыв» на улице, расширенный итог срыва, «Испугался» дома, строку триггеров на «Сегодня», графики в Истории (большие реакции в неделю, средняя дистанция, время восстановления), «Работа с порогом» в группе «занятия» на вкладке «Собака», блок «на что реагирует» в брифе ситтера. Без режима «Сорвался» остаётся в шторке инцидента.

### 7. «Другое…»

Компонент: последний чип `Другое…` (пунктир, `Action.primary`-текст) в `TGChipGroup`. Тап раскрывает поле **под чипами в той же шторке** (клавиатура открыта, «Готово»). Свой ответ, введённый дважды, становится обычным чипом этой собаки (после «Другое…» не прячется). Текст попадает в запись, в Историю (поиск) и в отчёт врачу. `UsageLog` пишет только «выбрано Другое · <id списка>». В «Данные → Журнал действий» — кнопка «Поделиться своими вариантами»: список своих текстов без клички, имён и времени, отправка только по нажатию.

Списки с «Другое…»: как попросил · особенности стула · что случилось дома · что случилось на улице · чем вырвал · что подобрал (только поле) · на что сорвался · как реагировал · что помогло · от чего испугался · дело ухода · что на снимке.
Без «Другое…» (список полный): как сходил · форма стула · как близко · мог взять лакомство · пришёл в себя за · кого зовём.

### 8. Вкладка «Собака»

Шапка (аватар, порода · возраст · вес; меню ▾: собаки, «Завести ещё собаку») → «Если что-то случилось» → **каждый день**: Питание и режим · Уход и прививки (в значении — ближайшая прививка) · Вес → **занятия**: Занятия и шаги · Подготовка к процедурам · Перенос навыка (Pro) · (поведение) Работа с порогом → **когда спросят**: Документы и контакты · **Отчёт врачу** (новый вход, бесплатно) · Цикл (условие) → **поездки**. Строку «Завести ещё собаку» из списка убрать.

Документы: заготовки названий + «Жетон и налог», «Страховка»; поле «срок» — напоминание в утренней сводке. Отчёт врачу: выбор языка — на первом экране отчёта.

### 9. История, Здоровье, Семья

- История: фильтр + «лечение»; карточки завершённых курсов («Левотироксин · 12 недель · 166 доз · 2 пропуска · вес 8,1 → 7,8 · Отчёт врачу ›»); поиск по тексту, включая «Другое…»; графики режимов.
- Здоровье: первой строкой «Если что-то случилось»; «Прививки и визиты» → «Уход и прививки»; «Вес и симптомы» → «Вес»; «Прошлые курсы →» ведёт в фильтр Истории.
- Семья: пустое состояние — одна карточка «Кто ещё кормит?»; «Пригласить» → выбор **Семья** (= `caregiver`) · **Ситтер** (= `helper`) · **Врач** (= `observer`) → лист «Поделиться»; в карточке участника — «Доступ до» (необязательно); со-владелец и права поимённо — там же.

### 10. Онбординг — 3 шага

Привет → 1 · Собака (кличка, вес) → 2 · Режим (еда, лечение, туалет) → 3 · Уведомления → «Сегодня» с «Учусь ритму». Шаги «Уход» и «Семья» удаляются: уход появляется строкой на «Сегодня» при первом сроке (стартовый набор `SeedData.attachStarterCare` остаётся), семья — карточкой на 3-й день.

## Состояние и модель данных

Одна миграция `V4` в `TogoShared/Domain/SchemaVersions.swift`:

- `Dog.toiletMode: ToiletMode` (`outdoor` по умолчанию · `pad` · `transition`), `Dog.logsPad: Bool = false`, `Dog.behaviorWork: Bool = false`.
- `LogKind.pad` — пелёнка.
- `IncidentKind`: + `fright`, + `scavenged`; `missedPad` — подпись `puddle` в режиме пелёнки (отдельный кейс не нужен).
- Новые enum: `FrightCause`, `ReactionStyle`, `ReactionRecovery`, `ReactionHelp`; `LogEvent.couldEat: Bool?`.
- Тексты «Другое»: поля `…Other: String?` у `LogEvent` для каждого списка (askSignal, stoolFlag, incident, vomit, scavengedWhat, reactionTrigger, reactionStyle, reactionHelp, fright) и модель `CustomChoice { dogID, listID, text, uses }` для превращения в чип после 2 использований.
- `NeedAsk { id, dogID, at, verdict, resolution: pending | toilet | notToilet }` — «Не сейчас» и исход просьбы; `pending` разрешается лениво при следующем расчёте вердикта (60 минут, была ли лужа).
- `ActiveSession.origin: needs | walk` вместо двух видов сессии.
- `FamilyMember.accessUntil: Date?`; `DogDocument.expiresAt: Date?`.
- Настройки уведомлений в `Settings`: `doseLeadMinutes (0/5/10/15)`, `doseOverdueReminder`, `notifyFamilyDose`, `notifyFamilyMeal`, `notifyFamilyOuting`, `notifyFamilyIncident`.

Новые поля уезжают в общий дневник → обновить `SharedDiaryPayloads`, выкатить схему CloudKit (`Tools/deploy_cloudkit_schema.sh`) **до** сборки, проверить миграцию установкой поверх TestFlight-сборки, а не на чистом симуляторе.

## Токены

Без новых сырых значений. Используются существующие: `Token.Action.primary/done/doneText`, `Token.Status.waiting/waitingBg` (окно натощак и плитка «Срыв»), `Token.Status.overdue/overdueBg/overdueText` (тревога, кровь, инцидент), `Token.Surface.screen/card/sunken`, `Token.Ink.primary/secondary`, `Token.Radius.tile/control/sheet`, `Token.Size.tapTarget`.
