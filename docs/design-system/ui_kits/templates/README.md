# Универсальные шаблоны

`index.html` — четыре экрана из компонентов Graphite: **Главная** (главная карточка с метрикой и действиями, быстрые действия, плитки, недавнее), **Список** (поиск, фильтры-чипы, выбор нескольких, удаление с подтверждением и отменой), **Деталь** (шапка, метрики, таймлайн, заметка), **Настройки** (профиль, тумблеры, меню, дата, слайдер, опасное действие).

Слева переключаются продукт (умный дом / дневник собаки / планер ленты), состояние данных (данные, загрузка, пусто, ошибка, нет сети), ширина 390 / 320 pt, размер текста L / XL / AX1, тема и акцент.

## Новый продукт

Добавьте объект в `presets.js` с той же формой: `tabs`, `noun` (склонения для «Удалить 3 …»), `home`, `list`, `detail`, `settings`. Экраны и компоненты не трогаются.

Поля экрана — 16 на 320–374 pt и 20 от 375. Все три пресета проверены на 320 pt + AX1: ничего не выходит за поля.
