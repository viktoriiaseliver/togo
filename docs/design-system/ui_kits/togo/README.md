# Togo · прототип

Пять вкладок Togo на компонентах Graphite: Сегодня · Собака · История · Семья, плюс Здоровье (лечение включено).

- **Сегодня** — вердикт «просится» (`VerdictCard`), «Вывожу» → режим прогулки (`WalkBar`), быстрая запись в два тапа (`QuickLog` + шит «Как попросил?»), доза (`DoseCard`), окно натощак после дозы (`FastingWindow`), карточка слияния (`MergeCard`).
- **История** — `DiaryEntry`, удаление обратимо 5 с и оставляет след.
- **Собака** — профиль и «Если что-то случилось» (`EmergencyCard`).
- **Семья** — участники и «Пригласить человека».
- **Здоровье** — дозы, отчёт врачу.

Переключатели: 390/320 pt, тема, размер текста L / XL / AX1.
