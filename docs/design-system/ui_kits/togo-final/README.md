# UI kit · Togo Финал

Интерактивная сборка финального стиля из `Togo ФИНАЛ.dc.html` на компонентах Graphite.

- `index.html` — оболочка: тема, состояние «Сегодня», таб-бар.
- `TodayScreen.jsx` — «Сегодня» T5+: `ReadingCard` вне скролла, лента `FeedRow` + `SwipeRow`, сжатие по прокрутке (p = scrollTop / 150), тост «Отменить»; `RecordSheet` — шторка «Записать…».
- `StockScreen.jsx` — `StockCard` по уровням и шторка «Купил» со сроком годности.

Полный набор экранов (онбординг, профиль, система, iPad) — в `Togo ФИНАЛ.dc.html` и `design_handoff_togo_final/`.
