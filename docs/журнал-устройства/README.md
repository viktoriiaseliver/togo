# Журнал с устройства — копии

Журнал действий и `startup.log` забираются с телефона в `build/`
(`make usage`), а `build/` сносит любой `make clean`. Единственные копии
данных с устройства лежали там — поэтому копии кладутся сюда.

- `usage-2026-09-21-до-сноса.jsonl` — 112 действий, снято 21.09.2026 13:56,
  **перед чистым сносом приложения с телефона**. После сноса на устройстве
  журнала нет: контейнер приложения удаляется вместе с ним.
- `startup-2026-09-21-до-сноса.log` — 199 строк, последняя запись 04.09.

Выводов по этим данным делать нельзя: большая часть действий приходится
на дни правок, то есть на собственные проходы по экранам, а не на жизнь
приложения. Подробнее — `СТАТУС.md`, раздел «Журнал действий».
