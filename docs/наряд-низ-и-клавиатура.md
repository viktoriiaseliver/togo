## Пункт 1. Кадр `DogStep` при поднятой клавиатуре

**Ось готова и отдана `projects-c5` готовым текстом** — метод
`замеритьПриКлавиатуре` с обратным `guard`. Он отказался класть её
**во время** своей приёмки `677fc79`, и отказался правильно: новый
сторож внутри чужой приёмки красит её своим предметом.

Числа объявлены **до** прогона, все по **оси ПЕЧАТИ** `замерить()`
(в шапке того же файла ось обратного знака — не перепутать):

```
перекрытие   ДО ≈ +165 pt   →   ПОСЛЕ ≤ 0
minY панели  ПОСЛЕ ≈ 446        уедет к ≈772 → ПРОВАЛ варианта, не успех
«Готово»     d7e275b НЕТ · 88c7b72 ЕСТЬ   ← контроль различимости кадра
контроль     :368 «Что будет прерывать» — ДО = ПОСЛЕ, правкой не тронут
контроль     154-режим-дня ≈ −40,0 как 08.10 (ось стабильна 6 дней)
```

**Почему этот кадр нельзя заменить зелёным прогоном.**
`ОнбордингНиз.замерить()` на `guard !app.keyboards.element.exists`
печатает «НЕГОДЕН», числа не печатает **нарочно** и возвращает `nil`.
Дефект живёт **только** при поднятой клавиатуре — то есть сторож
отбраковывает единственное состояние, в котором есть что мерить.

> **Зелёный `ОнбордингНиз` про эту правку не говорит ничего.**

## Пункт 2. Перенос в `TGScreen` + переписывание сторожа

**ТОЛЬКО после пункта 1.** Не подтвердит кадр — вариант мёртв ценой
одного экрана, и это тоже результат.

Переписывать `TogoTests/ЗапасПодНизомTests.swift` **тем же коммитом**,
и **переписывать, а не удалять**: запрет остаётся («запас не задаётся
ни числом, ни своей арифметикой»), меняется то, чем он держится —
«низ отдан системе» вместо «высота измерена руками». Иначе через неделю
три покрасневших ожидания прочтутся как регрессия вёрстки.

Сюита требует дословно: тело содержит `высотаНиза`, содержит
`GeometryReader`, содержит `Color.clear`. Правка каркаса выбрасывает
**ровно эти три вещи**.

**Подделка возможна** — у этой сюиты объявленного красного нет, значит
`check_guard.py` не откажет до подделки (редкий случай):

```bash
make guard ФАЙЛ=Togo/DesignSystem/Components/TGScaffolds.swift \
           НАБОР=TogoTests/ЗапасПодНизомTests
```

## Пункт 3. Кадр для `TGSheet` — отдельный, и вот почему

**Четыре адреса из семи — листы, а не экраны:**

```
TGScreen   DogStep · DogEditorScreen · WeightScreen
TGSheet    MedicationEditorSheet · PrescriptionEditor
           LabResultEntryFlow · LabResultRowEditor
```

`NavigationStack` внутри `TGSheet` **не найден**. Что панель
`placement: .keyboard` обойдётся без него — взято **из устройства
SwiftUI, а не измерено здесь**. Оговорка стоит в коде рядом с первым
листом, но **оговорка не замер**.

Снимать на `LabResultEntryFlow`: там полей `.decimalPad` больше всех
в приложении — **три на каждую строку бланка**, и человек набирает их
подряд. Если «Готово» где-то не покажется, то там.

> **составлен раньше** её решения и доставлен **позже** него. Он

> нового решения не следует** — проверять это надо и в задании,
> пришедшем вместе со сменой, не только в наряде.
