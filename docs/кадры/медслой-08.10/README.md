# Медслой — приёмка кадром, 08.10.2026, коммит `4f2a11f`

Три дороги (`TogoUITests/МедслойДороги`) — визиты, диагнозы, назначения:
20 кадров, светлая 0,82–0,86 против тёмной 0,09–0,19. Плюс перепроверка
дороги анализов: 8 кадров, прогон зелёный.

## Три находки предыдущей партии ЗАКРЫТЫ, проверено пикселем

```
часы от дозы   доза 20:00 · забор 20:02 → «забор через 2 мин после дозы»
               числа сходятся; округления на вводе больше нет
орфография     красной волны под «нмоль/л» нет
«Норма от»     видно целиком, не половиной
```
Оговорка по третьему: **«Норма до» при поднятой клавиатуре всё ещё
за нижним краем.** Половинной строки больше нет — это и был дефект;
содержимое ниже сгиба прокруткой достижимо, но кадром это не проверить.

## Что нашлось на новых дорогах

**1. Сегмент статусов диагноза обрезан.** «рабочая гипо…» с многоточием
на **стандартном** кегле и широком экране (iPhone 17 Pro). Соседние
«подтверждён» и «снят» влезают. На 320 pt и AX1 будет хуже.
Смысл спасает пояснение под сегментом, но сам орган управления
показывает обрезанное слово.

**2. Строка «Препарат Левотироксин» уходит под кнопку** на форме
назначения при поднятой клавиатуре — та же семья, что `TGScaffolds:147`.

**3. Кадр `32-назначение-окно-контроля` не содержит окна контроля.**
В этом прогоне он кончается кнопкой «Добавить»; блок остался ниже.
Это не дефект продукта — дефект имени: **имя кадра утверждает
содержание, а содержание зависит от позиции прокрутки в конкретном
прогоне.** Тот же класс, что ярлык темы в строке вывода: имя
печатается до съёмки и не ломается.

## Чего этот набор не отвечает

Различимы ли три статуса по силуэту значка — **кадром не взять**:
в засеве одна запись, то есть один значок из трёх. Нужен список
с тремя статусами разом.
