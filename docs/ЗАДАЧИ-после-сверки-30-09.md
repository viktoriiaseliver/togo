# Задачи после сверки карточки с кодом — 30.09.2026

сверена с кодом построчно. То, что можно было сделать без Mac и без живых
телефонов, сделано в ветке `claude/dazzling-mendel-a5r4o6` (журнал —
`docs/journal/2026-09-30.md`). Ниже то, что остаётся команде, по убыванию цены.

     `.chartYScale(domain: .automatic(includesZero:))`.

     с `import Combine`, `PersistentIdentifier.entityName`.
   - `Togo/App/RootView.swift` — `#Predicate { $0.walkEventID == walkID }` c `UUID?`.
   - `Togo/App/AppState.swift` — замыкание отката в словаре под
     `@ObservationIgnored`; `proАктивен`, `закрыта(_:среди:гость:)`.
   - `TogoShared/Domain/Backup.swift` — экзистенциалы `any PersistentModel.Type`,
     `ObjectIdentifier` метатипа, `Schema.Entity.name` против имени класса
     (ловят тесты `eraseCoversSchema`, `replaceErasesEveryModel`).
   - `Togo/Features/Emergency/LostPoster.swift` — `ImageRenderer` в `.task(id:)`,
     `ShareLink(item: Image, …)`.
   - `Togo/App/TogoApp.swift` — `.onChange(of: subscriptions.isPro, initial: true)`.
   - `Togo/Features/Settings/DataPrivacyScreen.swift` — условный `Text`
     в `message:` у `confirmationDialog`.
   - Сторожа: `LocalizationCoverageTests` (добавлено ~90 ключей ru/fr/uk),
     `DesignLiteralTests`, `SchemaFrozenTests` (схема не менялась),
     `DeadLogicTests`, `SilentFailureTests`.
2. **Кадры приёмки на телефоне** (приёмка — по кадрам, не по «тесты зелёные»):

## Общий дневник и iCloud — нужен живой телефон

3. **Обмен в одну сторону.** Мама → Виктория доезжает, Виктория → мама — нет
   с 22.09. Причина не найдена (`СТАТУС.md`). Инструмент видимости отказа есть
   с `70af5b1`.
4. **Выложить схему CloudKit в production** — `Tools/deploy_cloudkit_schema.sh`,
   нужен management-токен cktool. Без этого отправка дозы с `medicationName`
   падает целиком.
5. **Удаление общего дневника целиком.** «Удалить все данные» теперь выключает
   обмен и зовёт `FamilyShare.stopSharing()`, но: зона `family` с записями
   в iCloud владельца не удаляется; гость не выходит из участников; удаления
   записей `FamilySync` не рассылает вообще (шлёт только сохранения). Нужны
   операции удаления зоны и выхода гостя, проверка на двух телефонах.
6. **Доходит ли пачечное `context.delete(model:)` через зеркало SwiftData
   до iCloud и других своих устройств** — не известно. Тексты сейчас говорят
   «стирает на этом телефоне». Проверить и, если доходит, поправить тексты
   на `DataPrivacyScreen`.
7. **Роль живёт только на своём телефоне.** Приглашённый получает все записи
   зоны, права роли у него не действуют. Решить продуктово: роль в payload или
   честная надпись на экране приглашения.
8. **Чужая отметка дозы.** Лестница t+30/t+60 теперь пересобирается по
   `ModelContext.didSave` (приём чужой дозы сохраняется обычным `save()`,

## Код — можно без телефона

13. **Права проверяются в нескольких местах**, а не в одном: `EventLog.record`,
    `DayPlanActions.checkPermission`, `claim`, `QuickLogIntents` (Siri пишет
    мимо `EventLog` — давняя находка). `DoseScheduler.markGiven` прав
    не проверяет. Свести в одну точку.
14. **Push-тексты доз и `proFeatures`/`lostOnDowngrade` не локализуются**
    (строковые кортежи через `.готовая`, литералы в `ReminderScheduler`).
15. **Утренний бриф** — текст замораживается при планировании и пересобирается
    только при открытии приложения. Уход «на завтра» считается от момента
    планирования.
16. **Мёртвый ключ каталога** «%@ уже записана в %@» (заменён на
    «%@ · уже записано в %@») и «Зелёная полоса — коридор, который назвал врач.»
    — убрать при следующем `make texts`, помня, что `make texts` сейчас стирает
    283 украинских перевода (`СТАТУС.md`).
17. **Инструкция ситтеру, история веса, занятия, поездки, запас корма и фото
    в общий дневник не ездят** — так и написано на `SharedDiaryScreen`. Решить,
    что из этого нужно второму человеку.

17a. **Тосты не переводятся.** `AppState.showUndo(_ message: String)` и
    `RootView` → `Text(toast.message)` с `String` — это verbatim: француз
    и украинец видят русский текст на каждом «Записано · …», хотя ключи
    в каталоге лежат. Перевести параметр на `String.LocalizationValue`
    (или `LocalizedStringResource`) и пройти все вызовы — часть передаёт
    готовую `String` (`DuplicateGuard.message`), их обернуть.
17b. **`DoseScheduler.unmark` берёт первую отметку на минуту.** У каждого
    телефона своя отметка той же дозы с другим id; снятие может снять не ту.
    `markGiven` починен 30.09 (данная любым телефоном отметка главнее своей
    открытой, тест `foreignGivenBlocksOwnOpen`), `unmark` — нет.
