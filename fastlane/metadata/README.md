# Тексты для App Store Connect

Разложены по структуре fastlane deliver: `fastlane/metadata/<локаль>/<поле>.txt`.
Загрузить можно как fastlane (`fastlane deliver`), так и руками — файлы
самодостаточны.

Английская локаль пока не заполнена: язык разработки — русский, и переводить
тексты машинно для магазина хуже, чем не публиковать локаль вовсе.
Французская (`fr-FR/`) — черновик 22.09.2026 по словарю `seo-optimizer`,
в ASC не загружать, пока интерфейс не заявит `fr` (см. `Togo-Info.plist`,
`CFBundleLocalizations`). См. раздел «Чего пока нет» в README.
