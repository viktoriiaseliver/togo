# Тексты для App Store Connect

Разложены по структуре fastlane deliver: `fastlane/metadata/<локаль>/<поле>.txt`.
Загрузить можно как fastlane (`fastlane deliver`), так и руками — файлы
самодостаточны.

Английская и французская локали пока не заполнены: язык разработки — русский,
и переводить тексты машинно для магазина хуже, чем не публиковать локаль
вовсе. См. раздел «Чего пока нет» в README.
