# Тексты для App Store Connect

Разложены по структуре fastlane deliver: `fastlane/metadata/<локаль>/<поле>.txt`.
Загрузить можно как fastlane (`fastlane deliver`), так и руками — файлы
самодостаточны.

Английская локаль пока не заполнена: язык разработки — русский, и переводить
тексты машинно для магазина хуже, чем не публиковать локаль вовсе.
Французская (`fr-FR/`) — **заливать можно, условие снято 23.09.**
Запрет стоял потому, что интерфейс не заявлял `fr`: `Togo-Info.plist`
держал `CFBundleLocalizations` со списком из одного русского. Ключ убран
(он же давал «несколько русских языков»), и языки бандл называет папками
сам. Замер: `Bundle.main.localizations` — `fr` и `ru`, без повторов,
сторож «Языки приложения» держит это тестом. В бандле `fr.lproj`,
2029 строк из 2123.

Чего во французской карточке пока нет — правовых страниц на французском:
`togo/fr/terms.html` и `privacy.html` отдают 404 *(устарело: проверка
24.09.2026 — fr и uk страницы privacy/terms/support отдают 200)*, перевод лежит
в `Tools/site_fr.py` и подключается отдельно. Пока страницы не подняты,
ссылка «Conditions d'utilisation» ведёт на английские условия.
