# Togo

iOS-дневник собаки: когда выводили, когда кормили, каким был стул.
Общий дневник на семью через CloudKit, виджеты, Live Activity.

## Прежде чем работать

**Источник правды — только git** (решение 22.09.2026). Всё, что не
лежит в репозитории, — зеркало или чужая память, и при расхождении
проигрывает без обсуждения.

1. **Код и `git log`** — что на самом деле сделано. Коммит и тест
   весят больше любой записи о них.
2. **`СТАТУС.md`** — срез проекта, блокеры и чему нельзя верить.
   Правится в том же коммите, что и работа, которую описывает.
3. **`docs/journal/`** — последняя запись сессии, `docs/JOURNAL.md`
   — оглавление.

Notion для проектов с 22.09 не ведётся — не читать и не писать; общее
правило четырёх проектов — `~/Projects/CLAUDE.md`.

Состояние App Store Connect — вне git и потому только через API
(раздел ниже), не по памяти и не по документам.

Закончив работу: запись в журнал (`make journal` заводит файл за
сегодня), верх `СТАТУС.md`, коммит. Незакоммиченное не существует.

## Устройство

- `README.md` — быстрый старт, что внутри, принятые решения.
- `docs/ARCHITECTURE.md` — слои и правила.
- `Makefile` — все команды: `make help` покажет список.

Коротко о том, что чаще всего нужно:

```bash
make unit                      # только модульные тесты — быстрая обратная связь
make device TEAM=L7CPH7W5QW    # поставить на подключённый iPhone
make usage                     # забрать с телефона журнал действий
```

## Источники правды

- **Репозиторий** — единственный. Чаты, отчёты агентов, память
  помощника — производные; расходятся с git — правятся под git. Notion
  для проектов не ведётся.
- **Состояние в App Store Connect** — только через API, не по памяти
  и не по `docs/APP-STORE.md`: файл сверялся с ASC 21.09 и стареет
  с каждым днём без сверки.
  `GET /v1/builds?filter[app]=6805876636&include=buildBetaDetail`
- **Токены** — `DesignTokens/tokens.json`; сгенерированное не править
  руками, `make tokens-check` валит расхождение.
- **Тексты витрины и интерфейса** — перед каждой отправкой сборки
  прогонять через скилл `seo-optimizer`.
