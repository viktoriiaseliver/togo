# Togo

iOS-дневник собаки: когда выводили, когда кормили, каким был стул.
Общий дневник на семью через CloudKit, виджеты, Live Activity.

## Прежде чем работать

**Источник правды — только git** (решение 22.09.2026). Всё, что не
лежит в репозитории, — зеркало или чужая память, и при расхождении
проигрывает без обсуждения.

1. **Код и `git log`** — что на самом деле сделано. Коммит и тест
   весят больше любой записи о них.
2. **`СТАТУС.md`** — срез проекта, блокеры и чему нельзя верить.
   Правится в том же коммите, что и работа, которую описывает.
3. **`docs/journal/`** — последняя запись сессии, `docs/JOURNAL.md`
   — оглавление.
4. **Отзывы живых людей** — `source Gamut/.env.asc && python3
   ~/Projects/отзывы.py Togo`. Единственный вход в проект, которого
   git не знает по устройству: их пишут снаружи и никто не кладёт
   в репозиторий.

   Шаг стоит минуту, и его цена измерена 07.10.2026: отзывы не снимал
   никто **девять дней** (кадры скачаны 28.09, следующие — 07.10
   08:05), а в них лежал живой дефект розданной сборки. Проверяется
   датой файлов в `~/Projects/.отзывы/Togo/`.

   > **Отзыв, который никто не прочитал, — это не обратная связь,
   > а её видимость.** Человек потратил время и получил молчание.

Notion для проектов с 22.09 не ведётся — не читать и не писать; общее
правило четырёх проектов — `~/Projects/CLAUDE.md`.

Состояние App Store Connect — вне git и потому только через API
(раздел ниже), не по памяти и не по документам.

Закончив работу: запись в журнал (`make journal` заводит файл за
сегодня), верх `СТАТУС.md`, коммит. Незакоммиченное не существует.

## Устройство

- `README.md` — быстрый старт, что внутри, принятые решения.
- `docs/ARCHITECTURE.md` — слои и правила.
- `Makefile` — все команды: `make help` покажет список.

Коротко о том, что чаще всего нужно:

```bash
make unit                      # только модульные тесты — быстрая обратная связь
make device TEAM=L7CPH7W5QW    # поставить на подключённый iPhone
make usage                     # забрать с телефона журнал действий
```

## Источники правды

- **Репозиторий** — единственный. Чаты, отчёты агентов, память
  помощника — производные; расходятся с git — правятся под git. Notion
  для проектов не ведётся.
- **Состояние в App Store Connect** — только через API, не по памяти
  и не по `docs/APP-STORE.md`: файл сверялся с ASC 21.09 и стареет
  с каждым днём без сверки.
  `GET /v1/builds?filter[app]=6805876636&include=buildBetaDetail`
- **Токены** — `DesignTokens/tokens.json`; сгенерированное не править
  руками, `make tokens-check` валит расхождение.

  > **Продуктовые цвета, записанные литералом, в повышенный контраст
  > не попадают по устройству; записанные через `var(--ядро)` —
  > попадают.**

  Замерено 07.10.2026 на пакете Graphite. Механизм: блоки
  `[data-contrast="high"]` живут в ядре (`colors.css`), а у продуктового
  слоя (`togo.css`) такого блока нет вовсе. Доказано сравнением, а не
  рассуждением: `--poster-err-sub: var(--status-error)` поднялся
  с 4,4955 до 6,0905 в Dark HC, а `--stock-low` в повышенном контрасте
  не меняется — и это единственная пара, не проходящая 4,5 в светлой.
  То есть повышенный контраст пропускает ровно ту пару, ради которой
  он нужен.

  **Правка 07.10, вечер: первая редакция этой записи была неверна
  наполовину.** В ней стояло «`--stock-low: #FFA15C` не сдвинулся
  ни в одном режиме». Перемер:

  ```
  togo.css:13   :root                   --stock-low: #FFA15C
  togo.css:19   [data-theme="light"]    --stock-low: #B85400   ← СВЕТЛОЕ ЕСТЬ
  togo.css      [data-contrast="high"]  блока нет вовсе        ← HC правда не трогает
  readme.md:91  пакет называет оба значения
  ```

  Светлая тема у продуктового слоя **есть**; не хватает ему только
  HC-блока. Инструмент, которым это мерили, читал светлые блоки
  правильно — ошибка была **в переносе находки в правило**, то есть
  в пересказе, а не в замере. Рядом с «пересказ устаревшего
  утверждения добавляет ему веса, которого у него не было»: здесь
  пересказ не устарел, а расширил утверждение с одного режима
  на все четыре.

  Это не про один оранжевый: так выпадет **всякий** следующий цвет,
  заведённый продуктовым слоем литералом. Проверяется за минуту —
  `python3 Tools/contrast_graphite.py` (источник — хендофф в git,
  `docs/design-handoff/design/tokens/`), полный разбор
  в `docs/контраст-graphite.md`.

  И граница самого замера, названная там же: он меряет **значения,
  а не кадр**. «Значение верное, а вызов бессильный» он не ловит —
  `opacity` на тексте и перекрытие цвета стилем видно только
  на пикселе.
- **Тексты витрины и интерфейса** — перед каждой отправкой сборки
  прогонять через скилл `seo-optimizer`.
